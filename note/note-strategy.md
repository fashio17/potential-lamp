# note コンテンツ戦略メモ

## 0. 前提の整理

| 項目 | 現状 |
| --- | --- |
| Instagram | 運用中・手応えあり（写真／短文・ビジュアル勝負） |
| note | これから開始（長文・言葉・思考の場） |
| 過去実績 | アメーバブログ 読者約2,500人／1記事500いいね規模。**「アパレル業界の裏側」が最も反応した** |
| 固有の資産 | アパレル業界の内側を長く見てきた経験・目利き・仕入れ／価格の感覚 |

**結論：noteの軸は「パリ」でも「コーデ」でもなく、「業界の中の人しか書けないこと」に置く。**

理由はシンプルで、パリ旅行記もコーディネート紹介も書き手が飽和している一方、
「原価」「仕入れ」「なぜこの値段なのか」「なぜこのブランドは日本に来ないのか」を
実感を持って書ける人はほとんどいない。しかも過去に**それで2,500人集まった実証がある**。
勝ち筋がすでに一度証明されている領域から始めるのが最短。

---

## 1. 大テーマ（noteの看板）

> **「アパレルの中にいた人間が、服の"本当のところ"を書く」**

サブコピー案：
- 値札の向こう側を知っている人間の、服の選び方
- 業界歴◯年。買う側にはあまり話されないことを書きます
- おしゃれの話を、もう少しだけ深いところから

プロフィール文にこの一行が入るだけで、note内での立ち位置が決まる。
「ファッション好きの人」ではなく「業界を知っている人」として読まれる。

---

## 2. 三本柱（マガジンの構成）

### 柱① 業界の裏側 ｜ 引きの強さ担当（全体の40%）
最も拡散し、フォローの理由になる記事群。読者は「知らなかった」で動く。

- 服の値段はどう決まるのか（原価率のリアル）
- セールで安くなる服／絶対に安くならない服の違い
- 「日本未進出」のブランドが日本に来ない、本当の理由
- 展示会って何をしているのか。バイヤーは何を見て仕入れを決めるのか
- 同じ2万円のシャツでも、中身がまったく違う話
- なぜ日本のブランドはサイズ展開が狭いのか
- 売れる服と、いい服は、必ずしも一致しない

### 柱② 大人の服選び ｜ 検索と共感担当（全体の40%）
継続的に読まれ、有料化やリピートにつながる記事群。悩みが具体的なほど強い。

- 日本人はなぜ黒を着すぎるのか（そして夏の黒がしんどい理由）
- 体型が変わってから、似合う服が変わった話
- 「若作り」と「若々しい」の境界線はどこにあるのか
- 一枚二万円の服を、納得して買うための基準
- クローゼットの8割は、たぶんいらない
- 五十代からの制服化。決めておくと楽になる三つのこと
- 試着室で必ず確認している、地味だけど効く三箇所

### 柱③ 旅と店の観察記 ｜ ブランディング担当（全体の20%）
世界観と読み物としての楽しさ。パリの記事はここに入る。

- パリの人はなぜ、おしゃれに見えるのか（※執筆済み）
- Sézane本店の熱気。日本にこのブランドがない不思議
- 海外の店で、私が服より先に見ているもの
- 日本の百貨店とパリの路面店、客の"買い方"の違い

## 3. 最初の10本（この順番で出す）

1. **自己紹介記事**：なぜ書くのか。業界にいた人間として何を伝えたいのか。← 固定表示にする
2. 服の値段はどう決まるのか（原価の話）← 一番の引き。2本目にぶつける
3. パリの人はなぜ、おしゃれに見えるのか（執筆済み）
4. 日本人はなぜ黒を着すぎるのか
5. Sézane本店の話／日本に来ないブランドの事情
6. セールで安くなる服、ならない服
7. 「一枚二万円」を納得して買うための基準
8. 体型が変わってから、服との付き合い方を変えた話
9. 展示会とバイヤーの仕事の中身
10. クローゼットの整理は、捨てる話ではなく決める話

**ポイント：1本目に旅行記を持ってこない。** 1本目＝自己紹介、2本目＝業界の裏側。
この2本で「この人は何者か」が伝わると、3本目以降の旅行記も"業界人が見たパリ"として深く読まれる。

## 4. 運用ルール

| 項目 | 推奨 |
| --- | --- |
| 頻度 | 週1本（曜日固定・木曜か日曜の朝がおすすめ） |
| 文字数 | 2,000〜3,000字。今回の記事の長さがちょうどいい |
| 見出し | 4〜7個。スマホで読むので、こまめに区切る |
| 冒頭 | 3行以内に「何の話か」を出す。noteは冒頭で離脱が決まる |
| 締め | 必ず読者への問いか、明日できる具体策で終える |
| 画像 | 見出し画像は必須。自分で撮った写真が一番強い |
| ハッシュタグ | 5個前後。#ファッション #アパレル業界 #40代のおしゃれ など |

## 5. Instagramとの接続（ここが一番のレバレッジ）

すでにInstagramが機能しているなら、noteはゼロからの集客ではなく**受け皿**として設計する。

- note記事の核になる一節を、Instagramのカルーセル3〜5枚に切り出して投稿
- 最後の1枚を「続きはプロフィールのリンクから」にする
- プロフィールのリンクをnoteに（Linktree等を挟まず直リンクの方が落ちにくい）
- ストーリーズで「今こういう記事を書いています」と制作過程を出す
- 逆に、note記事の中でInstagramには載せきれない"長い話"を書く。役割を分ける

**Instagram＝知ってもらう／note＝信じてもらう。** この分担を崩さない。

## 6. その先（3〜6ヶ月後に考えること）

軌道に乗ってから検討すればよく、最初から手を出さない。

- **有料マガジン**（月500〜1,000円）：業界の裏側シリーズを深掘り
- **単発の有料note**（500〜1,500円）：「大人のワードローブの作り方」など保存性の高いもの
- **メンバーシップ**：質問に答える形式。アメブロ時代の読者との関係性が再現できる
- **個人ショップ／これから業界に入る人向け**の実務コンテンツ：ここは競合がほぼいない

---

## 7. やらないほうがいいこと

- 毎日更新を目標にする（続かないうえ、1本の密度が落ちる）
- コーディネート紹介だけで勝負する（Instagramの下位互換になる）
- ブランドの悪口として読める書き方（業界人としての信用が最大の資産）
- 最初から有料にする（まず無料で30本、読者との関係をつくる）
