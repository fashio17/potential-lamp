# 17.8万形式のテロップ（2026年9月5日〜）

17.8万回のリールの現物を実測して決めた形です。根拠は `README.md` の
「17.8万回のリールの現物を測った」の節。

## 数値

| 項目 | 値 |
|---|---|
| 1枚の行数 | **原則1行**（2行にしてよいのは表紙だけ） |
| 1行の長さ | **14字まで**（68pxで画面幅の88%） |
| 総文字数 | **90〜110字**（1秒あたり4〜5字） |
| フォント | **68px 固定**（短い行はそのまま短く出す） |
| 縦位置 | **`y=(h-th)/2`（中央）**。17.8万回は62%だったが、2026/9/5にご本人が「真ん中が良い」と決定 |
| 横位置 | `x=(w-tw)/2`（中央ぞろえ。ここは17.8万回も同じ） |

## drawtext の指定

```bash
ST="fontfile=$FT:fontcolor=white:box=1:boxcolor=black@0.58:boxborderw=26:\
shadowcolor=black@0.5:shadowx=2:shadowy=2:line_spacing=18:x=(w-tw)/2"
d () { echo "drawtext=${ST}:textfile=$D/$1.txt:fontsize=68:y=(h-th)/2:enable='between(t,$2,$3)'"; }
```

## 書くときの型

**具体的な体験をひとつだけ話す。** 理論の引用と比較文化の考察はキャプションに置く。

**そのうえで、着地は必ず「仕組み」にすること。**
ご本人は**ファッション心理学者**であり、**スタイリストではありません**。
短くすると「着こなしのコツ」に見えやすいので、書いたら必ず読み返す。
研究テーマは「**似合うの仕組み**」と「**似合うを自信に変える仕組み**」です。

17.8万回の全文（8枚・83字）がお手本です。

```
1 旅行にパンツを持っていくの、／やめました   ← 表紙だけ2行。一人称の決断
2 この黒ワンピース1枚で、
3 パリと、                              ← 4字で1枚にしてよい
4 ニューヨーク
5 変えたのは、羽織るものだけ
6 そのまま、夜のレストランにも
7 服が減るほど、
8 旅は、自由になる
```

## 書き終わったら必ず数える

```bash
cat $D/*.txt | tr -d '\n' | LC_ALL=C.UTF-8 wc -m   # 90〜115 に収まっているか
```

**`LC_ALL=C.UTF-8` を必ず付けること。** 付けないと日本語が1文字3バイトで数えられ、
3倍の数字が出ます（一度ひっかかりました）。

## 絵のほうの決めごと（2026/9/5 追記）

テロップだけ整えても、画が分からなければ意味がありません。

1. **表紙は「遠目でご本人のスタイルが分かる全身」**。17.8万回もこれでした。
2. **1カットで何が映っているか分かる引きにする。** 布のアップは伝わりません。
3. **引きの画（街・建物・店構え・売り場の全体）を必ず混ぜる。**
4. **同じ素材は他のリールで二度と使わない**（`素材台帳.md` の「使用済み素材の一覧」）。
5. **1本の中でも、同じ写真から4カット以上取らない。**
