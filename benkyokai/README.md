# 勉強会 ― Instagram → LINE → 勉強会 → 個別相談

たくむさん型（登録直後に勉強会へ誘導し、参加した人に特典を渡す）を、えりりんさんの事業に合わせて組み直した一式です。

### 再生成

```bash
npm install pptxgenjs
node build_slides.js
```

- サイズ：`LAYOUT_WIDE`（16:9）／配色・書体は既存教材と共通
- **写真とAI出力は差し込み枠（点線）にしてあります。** 実物を貼ってください

## なぜこの形にしたか

| 変えた点 | 理由 |
| --- | --- |
| 動画を必須ステップから外した | **LINEの動画は再生されません。** 予習（任意）に降格し、必須は「予約」と「参加」にしました |
| 「セミナー」を「勉強会」に | 売り込まれる場に見えません。**大学教授・アカデミアという看板と同じ言葉**です |
| 聞く会ではなく**作る会**に | 「勉強会」は学ぶこと自体が目的の人を呼びます。えりりんさんのお客様は**資格を増やし続ける層**なので、そのままだと最も買わない人が集まります |
| 提出を挟んだ | **提出した人＝実行する人。** ここで個別相談の母集団が絞れます |
| 募集をストーリーに | 24時間で消えるので、**煽らずに締切が作れます** |
| 診断を未予約者に回した | 予約が重い人を、3分のもので拾い直します |

## 全体像

```
リール／フィード           → 見つけてもらう
ストーリー（週1周・7ステップ）→ 勉強会の募集（⑦「行動」の枠）
LP（常設）                 → 診断を体験 → LINE登録
   ↓
LINE登録直後               → 勉強会の予約【唯一のお願い】
   ↓                        └ 予習として8分46秒の動画【任意】
勉強会 70分（自動ウェビナー）→ ワーク10分 → 提出
   ↓                        └ 特典：AIプロンプト集
個別相談 → 6ヶ月講座
```

## 勉強会の背骨

> **AIが弱いのではありません。渡す中身がないだけです。**
> 海外リサーチは、その中身を仕入れに行く作業です。

海外リサーチとAIは、別々の話ではありません。**リサーチが「中身」を作り、AIがそれを形にします。** ここがブレると、ただの詰め合わせになります。

## 運用の順番

1. **初回はライブで開催する。** どこで参加者が詰まるかが見えます
2. その録画を **UTAGE自動ウェビナー**に載せる（曜日＋時刻指定・週2枠・事前登録必須）
3. 以降はストーリーで毎週募集し、個別相談だけに時間を使う

## 絶対に外せない設定

**個別相談に申し込んだ人を、シナリオBから配信解除してください。**
これがないと、申込済みの方に勧誘が届きます。全体でいちばん印象が悪くなるところです。
