# Instagram ストーリー ― 勉強会の募集の型

## なぜストーリーで募集するのか

| | 役割 | 相手 |
| --- | --- | --- |
| リール・フィード | **見つけてもらう** | 新規 |
| プロフィールのLP | **常設の受け皿** | いつ来た人でも |
| **ストーリー** | **今回の募集** | すでにフォローしている人 |

ストーリーが強い理由は1つです。**24時間で消えるから、「今回だけ」が自然に出せる。**

LPに「今だけ」と書くと安っぽくなります。ストーリーなら、言わなくても伝わります。**上品さを保ったまま締切が作れる、唯一の場所です。**

---

## 5枚の型

**毎回この5枚です。** 中身だけ入れ替えます。考える時間をゼロにするのが目的です。

### 1枚目 ― 問題提起

**文字だけ。写真を入れない。** 情報を1つに絞ります。

```
Instagramを開くと、

みんな似ている。

そして、自分の投稿も
その中に混ざっている。
```

> **画面**：白背景／黒文字／中央寄せ。装飾なし
> **狙い**：手を止めさせる。2秒で「私のことだ」

### 2枚目 ― 共感（責めない）

```
これ、センスの問題じゃないんです。

見ているものが、
みんな同じだから。

日本の雑誌、
日本のインフルエンサー、
そして他のイメコンさんの投稿。

同じ材料からは、
同じものしか出てきません。
```

> **画面**：文字。行間を広めに
> **狙い**：原因を構造に置く。**能力のせいにしない**（これは講座全体の姿勢と同じ）

### 3枚目 ― 告知（日時とテーマ）

```
勉強会をひらきます。

「海外の視点」と「AI」で、
あなたにしか作れないリールをつくる

　◯月◯日（◯）20:00 -
　オンライン／70分／無料
```

> **画面**：ご自身の写真 or 海外で撮った1枚＋文字
> **狙い**：日付を入れる。**「セミナー」と書かない**

### 4枚目 ― 中身（ここで選別する）

**この1枚が、参加者の質を決めます。**

```
聞いて終わりにしません。

最後の10分、手を止めて
リールの構成を1本、
その場で作って持ち帰っていただきます。

情報を集めたいだけの方には
向きません。
```

> **画面**：文字
> **狙い**：**集めるだけの人をここで外す。** 人数は減りますが、来る人が変わります

### 5枚目 ― リンク

```
お席を取っておきますね。

　▼ 日程を選ぶ
　（リンクをタップ）
```

> **画面**：リンクスタンプを大きく。**画面の中央より少し下**（親指が届く位置）
> **狙い**：迷わせない。他の情報を一切入れない

## アンケート・質問スタンプを必ず使う

**5枚のうち2枚目のあとに1枚差し込みます。** これが最も反応が取れます。

### アンケート（2択）

```
リール1本作るのに、
どのくらいかかっていますか？

　□ 1時間以内
　□ 半日
```

### 質問スタンプ

```
投稿で、いちばん困っているのは
どこですか？

（ひとことで大丈夫です）
```

**答えた人には、そのままDMで案内できます。** 押し付けにならずに反応が取れるのが、ストーリーの一番強いところです。

そして、**集まった答えは、次の勉強会とリールのネタになります。** 聞くこと自体が仕入れです。

## 出す順番とタイミング

| いつ | 出すもの |
| --- | --- |
| 開催の**5日前** | 1〜2枚目＋アンケート（まだ告知しない） |
| 開催の**4日前** | 3〜5枚目（初回の告知） |
| 開催の**2日前** | 3・5枚目だけ再掲＋「◯名の方がご予約くださいました」 |
| **前日** | 5枚目のみ＋「明日です」 |
| **当日の朝** | 5枚目のみ＋「今夜です」 |

**5日前にいきなり告知しないでください。** 1〜2枚目で「自分のことだ」と思ってもらってから、3枚目で日付を出します。**順番を逆にすると、ただの宣伝になります。**

---

## 7つの心理ステップに乗せる

ストーリーは**週1周**させます。募集は、その中の**⑦「行動」**の枠に置きます。

| 曜日 | 心理ステップ | 出すもの |
| --- | --- | --- |
| 月 | ① 憧れ | お客様の変化、なりたい姿の話 |
| 火 | ② 信頼 | 理論・研究の話。ファッション心理学の視点 |
| 水 | ③ 共感 | 自分の失敗、日常 |
| 木 | ④ 応援 | 学んでいる姿、挑戦している姿 |
| 金 | ⑤ 気づき | 常識を壊す視点（「装いは心理的スーツです」など） |
| 土 | ⑥ 自分ごと化 | **「センスは才能ではなく、仕組みです」** |
| 日 | ⑦ 行動 | **勉強会の募集** |

**募集が浮かないのは、この流れがあるからです。** 毎週①〜⑥を積んでいれば、⑦は自然な着地になります。いきなり⑦だけ出すと、宣伝に見えます。

## 使い回しのしかた

**毎回ゼロから作らないでください。**

1. 1枚目・2枚目・4枚目は**ほぼ固定**。文言をそのまま使い回せます
2. 3枚目は**日付だけ差し替え**
3. 5枚目は**完全に固定**

変えるのは**日付と写真だけ**です。慣れると5分で作れます。

### 1枚目のバリエーション（飽きたら差し替え）

```
A：
Instagramを開くと、みんな似ている。
そして、自分の投稿もその中に混ざっている。

B：
「発信のネタが出てこない」
これ、ネタ切れじゃないんです。

C：
AIに書かせたら、
どこかで見たことのある文章が出てきた。

D：
資格は増えたのに、
仕事は増えていない。
```

**Dは強いですが、使いすぎないでください。** 刺さる代わりに、読んだ人を落ち込ませます。月1回までにしてください。

---

## やってはいけないこと

1. **「セミナー」と書かない。** 売り込まれる場に見えます。**勉強会**で統一
2. **「限定◯名」「あと◯席」を煽らない。** ストーリーは24時間で消えるので、締切は言わなくても伝わります。「◯名の方がご予約くださいました」までにしてください
3. **1枚に情報を2つ入れない。** 全部読まれなくなります
4. **告知だけを繰り返さない。** ①〜⑥を積んでいない週は、⑦を出しても取れません
5. **成果の数字を出さない。** 「月商◯◯万」の世界に自分から降りることになります
6. **リンクを画面の上のほうに置かない。** 親指が届きません

## 開催後にも1枚出す

**終わったら必ず出してください。** 次回の集客がここから始まります。

```
昨夜の勉強会、
ありがとうございました。

最後の10分で、
みなさんに手を止めていただいて

リールの構成を1本、
作って持ち帰っていただきました。

送っていただいたもの、
ひとつずつ読んでいます。

次回は◯月◯日です。
```

参加していない人が、**「そんなことをやっているのか」**と知る唯一の機会です。実際に送られてきたもの（許可を得たもの）を1つ載せると、次回の予約が変わります。
