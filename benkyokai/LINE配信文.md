# LINE配信文（勉強会版・実装用）

## 動線マップ

```
Instagram（リール／フィード＝新規、ストーリー＝募集）
   ↓
LP（診断を体験 → 登録）／ ストーリーから直接
   ↓
公式LINE  https://lin.ee/5ZCgX2F
   ↓
┌─ シナリオA：全員 ────────────────┐
│ A① 即時    勉強会の案内【お願いは予約だけ】 │
│ A② 翌日20:00  未予約の方へ（診断を渡す）    │
│ A③ 3日後20:00 未予約の方へ 最後の一押し     │
└──────────────────────────┘
   ↓ 予約したら A を解除して B へ
┌─ シナリオB：予約した方 ──────────────┐
│ B① 予約直後   予約完了＋予習（動画・任意）   │
│ B② 前日20:00  リマインド                │
│ B③ 開始1時間前 リマインド                │
│ B④ 終了30分後 提出のお願い               │
│ B⑤ 翌日20:00  ＜提出者＞個別相談          │
│              ＜未提出者＞もう一度見る案内   │
│ B⑥ 3日後20:00 締め                     │
└──────────────────────────┘
```

## この設計で守っている3つのこと

1. **登録直後のお願いは「予約」だけ。** 動画も診断も、ここでは出しません。1通に1つです
2. **動画を必須にしない。** LINEの動画は再生されません。予習として渡すだけにします
3. **提出した人にだけ個別相談を案内する。** 提出＝実行する人。ここで母集団が絞れます

## UTAGE 設定メモ

### シナリオの切り替え

| タイミング | 設定 |
| --- | --- |
| 勉強会を**予約**したとき | シナリオAを**配信解除** → シナリオBに登録 |
| 個別相談に**申し込んだ**とき | シナリオBを**配信解除** |

**2つ目を必ず入れてください。** これがないと、**申込済みの方にB⑤B⑥の勧誘が届きます。** 全体でいちばん印象が悪くなるところです。

### ラベル

| ラベル名 | 用途 |
| --- | --- |
| `勉強会_予約済` | B移行の判定 |
| `勉強会_参加済` | 視聴完了で付与 |
| `提出済み` | B⑤の出し分け |
| `個別相談_申込` | 全シナリオから除外 |

### 配信時刻

20:00 配信が多い設計です。UTAGE側で深夜配信の制限をかけている場合、時刻がずれることがあります。**必ずテスト配信で1周確認してください。**

### 運用で守ること

- **A①で動画も診断も出さない。** お願いは予約1つだけ
- **B①の予習は「任意」と明記する。** 必須にすると、見なかった人が来なくなります
- **B④の返信には必ず一言返す。** ここが個別相談の母集団です
- **提出していない人に個別相談を押さない。** 押すと、次の勉強会に来なくなります
- **「限定」「今だけ」を強く出さない。** B⑥の「今週いっぱい」程度に留めます
- **実績や金額の数字は出さない**
