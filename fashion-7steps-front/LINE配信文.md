# 【本命】1本版の配信

## 配信スケジュール

| # | タイミング | 内容 |
| --- | --- | --- |
| 0 | **登録直後（自動）** | あいさつ＋**動画をそのまま渡す** |
| 1 | 翌日 20:00 | 感想を聞く＋個別相談のご案内 |
| 2 | 3日後 20:00 | 「1番と2番」の話＋再案内 |
| 3 | 6日後 20:00 | 最後のご案内（枠の締め） |

**動画は登録直後に出します。** 「明日お送りします」で1日待たせると、その時点で熱が下がります。

個別相談の案内は**動画の中と、1通目（翌日）から**。0通目では動画を見てもらうことだけに集中します。

# 【会員サイト用】3本版の配信

会員サイトの無料コースに3レッスンを置く場合の案内文です。**LINE登録直後には使いません。**
1本版の動画を見た方に、「もっと知りたい方はこちら」として案内する位置づけです。

## 無料コースのご案内（動画視聴後、任意のタイミングで）

```
こんばんは。えりりんです。

先日の動画を最後までご覧くださった方から、
「もっと詳しく聞きたい」という
お声をいただきました。

ありがとうございます。

そこで、動画でお話しした内容を
3つのレッスンに分けて、
じっくり見られる形にしました。

　▼ 無料レッスン（3本・約34分）
　［会員サイトのURL］

　レッスン1　資格を取ったのに、なぜ選ばれないのか
　レッスン2　お客様が変わらない、本当の理由
　レッスン3　選ばれている人が、整えている7つ

ご登録いただいた方は
そのままご覧いただけます。

一度に見なくて大丈夫です。
お時間のあるときに、
少しずつ進めてみてください。
```

## 書くときの注意（共通）

- **動画は登録直後に渡す。** 待たせない
- **0通目では個別相談に触れない。** 動画を見てもらうことだけに集中する
- **「限定」「今だけ」を強く出さない。** 上品さと信頼感が、この事業の資産です。最後の1通の「今週いっぱい」程度に留めます
- **改行を多めに。** 1行は20文字前後、2〜3行ごとに空行を入れてください
- **実績の数字は出さない。** 出すと、比較のフィールドに自分から降りることになります
- **返信のハードルを下げる。** 1通目の「番号だけ返信」は、双方向のやりとりが始まるきっかけになります。LINEは返信があるアカウントほど届きやすくなります
