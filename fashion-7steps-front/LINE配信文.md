## この設計で守っている3つのこと

1. **1通につき、お願いは1つだけ。** 人は1通で1つしか動きません
2. **資料は返信待ちにしない。** 返信をトリガーにすると大半に届きません。選別はオファーの段階でやります
3. **①②では個別相談に一切触れない。** ここを我慢できるかで、④以降の届き方が変わります

## UTAGE への登録手順

以下は UTAGE の画面で設定する内容です。本文は下の①〜⑦をそのままコピーしてください。

### 1. シナリオを作る

`配信管理` → LINEアカウントを選択 → `シナリオ` → 新規作成

| 項目 | 設定 |
| --- | --- |
| シナリオ名 | `フロント｜動画→診断→個別相談` |
| 登録トリガー | 友だち追加（`lin.ee/5ZCgX2F` 経由の全員） |

### 2. ステップ配信の時間設定

**⚠ ここだけ注意してください。** UTAGE の経過日数は **登録した当日が「0日」** です。
下の表の「経過日数」の数字をそのまま入れれば、右の「実際に届くタイミング」になります。

| # | 内容 | 経過日数 | 時刻 | 実際に届くタイミング |
| --- | --- | --- | --- | --- |
| ① | 動画 | **0日** | 即時 | 登録した瞬間 |
| ② | 感想（番号1つ） | **1日** | 20:00 | 翌日の夜 |
| ③ | 診断 | **2日** | 08:00 | 翌々日の朝 |
| ④ | 資料＋個別相談① | **3日** | 08:00 | 3日後の朝 |
| ⑤ | 診断の活かし方＋個別相談② | **4日** | 20:00 | 4日後の夜 |
| ⑥ | 締め | **6日** | 20:00 | 6日後の夜 |
| ⑦ | セミナー案内 | ステップに入れない | — | **一斉配信**で別途送る |

**⑦はステップ配信に入れないでください。** セミナーは日程が決まってから送るものなので、ステップに固定すると日程が合わなくなります。⑥まで終わった人に対して、そのときに一斉配信で出します。

### 3. 夜間の配信ストップを確認

②⑤⑥は 20:00 配信です。UTAGE 側で深夜配信の制限をかけている場合、時刻がずれることがあります。**登録後、テスト配信で必ず1周確認してください。**

### 4. ②の返信を受けるラベル

②で番号（1〜4）が返ってきます。ラベルを4つ作っておくと、あとで使えます。

| ラベル名 | 付ける相手 |
| --- | --- |
| `壁1_資格を増やす` | 「1」と返信した人 |
| `壁2_AI任せきり` | 「2」と返信した人 |
| `壁3_心のブレーキ` | 「3」と返信した人 |
| `壁4_未分類` | 「4」と返信した人 |

自動でラベルを付ける設定（キーワード応答）を組んでもいいですが、**最初は手動で構いません。** 数が少ないうちは、返信に一言返しながら手で付けるほうが確実で、しかも会話が一往復するぶん到達率が上がります。

### 5. 個別相談に申し込んだ人を、ステップから外す

**これを忘れると、申込済みの人に⑤⑥の勧誘が届きます。** いちばん印象が悪くなるところです。

`https://utage-system.com/event/XZDWcN4ju08q/register` の申込アクションに、
**「このシナリオから配信解除」** を設定してください。

### 6. テスト

自分をテスト登録して、①が即時に届くか、リンクが4つとも開くかを確認してください。
特に **③の診断リンク**と**④⑤⑥の個別相談リンク**は、実際にタップして最後まで進んでみてください。

## 運用メモ

- **①②で個別相談に触れない。** これが全体でいちばん大事なルールです
- **②の返信には必ず一言返す。** 一往復するとLINEの到達率が上がります
- **「アカデミアと返信」は使いません。** 相手にとって意味の分からない言葉なので返信されません。資料は④で自動的に届きます
- **「限定」「今だけ」を強く出さない。** 上品さと信頼感がこの事業の資産です。⑥の「今週いっぱい」程度に留めます
- **実績や金額の数字は出さない。** 出すと比較のフィールドに自分から降りることになります
- **セミナー後**：参加者には個別相談を再案内できます。①〜⑥を通った人が⑦で戻ってくる設計です

## LP側で1つだけ直したいこと

`/p/video1` の動画下、「見終わったあとに」の欄に

> まずは簡単な診断とAIでの具体化から試してみてください

と書かれていますが、**そこに診断へのリンクがありません。**
やる気になった人が、その場で行き先を失っています。動画の NEXT STEP ①「まず診断してみる」とも噛み合いません。

**対応：** その一文の直下にボタンを1つ置いてください。

```
　▼ なりたい自分ギャップ診断（3分・無料）
　https://utage-system.com/p/nLlD4Z9mSVWr
```

診断は10個すべて個別に URL を発行済みです（一覧は `診断アプリURL一覧.md`）。
LP に置く場合、③の配信文は「もうやった方向け」に一言添えるだけで、そのまま使えます。
