# 無料ミニ講座（全3本）― Instagram → LINE 登録者向け

インスタから LINE に登録したばかりの方に見せる、フロント動画一式です。着地は**個別相談のお申込み**。

受講生向け教材（`../fashion-7steps/`）はそのまま残してあります。**同じ7ステップを扱いますが、役割が逆です。**

| | 受講生向け教材 | この無料ミニ講座 |
| --- | --- | --- |
| 相手 | 入会済みの受講生 | まだ何も買っていない人 |
| 話すこと | **どうやるか**（実装） | **なぜ今のままだとうまくいかないのか**（原因） |
| 7ステップ | あなたがやる7つ（行動計画） | 選ばれている人が整っている7つ（**地図**） |
| ワーク | ワークシート・宿題あり | なし（チェック4問のみ） |
| 尺 | 講義90分＋ワーク60分 | 10分＋12分＋12分（合計約34分） |

## 3本の構成

| # | タイトル | 尺 | 役割 |
| --- | --- | --- | --- |
| 1 | 資格を取ったのに、なぜ選ばれないのか | 約10分 | 「私のことだ」と思ってもらう。原因を能力から引き剥がす |

## 無料で出すもの／有料に残すもの

**この線引きが、この設計のいちばん大事なところです。**

| | 内容 |
| --- | --- |
| **無料で出しきる**（＝「なぜ」） | 診断がコモディティ化した理由／「診断ができます」が機能しない理由／診断結果が実行されない理由／観念という考え方／DISCOVERY・AWAKENESS・Circulation の**概念**／「似合う」と「なりたい」のズレ／7ステップの**一覧**（各1行） |
| **有料に残す**（＝「どうやるか」） | セッションの具体的な質問項目と進め方／商品の3層設計と価格／発信の7つの心理ステップの中身／LINE・LP の導線設計／UTAGE・L Message の実装／ワークシートと添削 |

出し惜しみすると、よくある集客動画になります。逆に「どうやるか」まで出すと、講座に入る理由がなくなります。**「なぜ」は全部出す。「どうやるか」は出さない。** これだけ守ってください。

## しゅうへいさん方式（スクールサイトの一部無料化）について

この3本は、**そのまま会員サイトの無料パートとして置ける設計**にしてあります。運用は2通りあります。

### パターンA：LINEステップ配信（まずはこちら）

LINE登録 → 翌朝から3日連続で動画URLを配信 → 3通目で個別相談。`LINE配信文.md` がそのまま使えます。

- 動画は限定公開のYouTube、または UTAGE のページに置くだけで始められます
- **今すぐ始められるのが利点。** まずここで反応を見てください

### パターンB：会員サイトの無料コース（一部無料化）

UTAGE の会員サイトに「無料コース」を作り、LINE登録者に無料アカウントを発行します。

```
会員サイト
├─ 無料コース：選ばれるファッションのお仕事（← この3本）
│    レッスン1　資格を取ったのに、なぜ選ばれないのか
│    レッスン2　お客様が変わらない、本当の理由
│    レッスン3　選ばれている人が、整えている7つ
│    ＋ 個別相談のご案内
└─ 有料コース：6ヶ月実践講座（既存）
```

**利点**：無料の人と有料の人が同じ場所にいるので、「続きがある」ことが自然に伝わります。無料コースの下に有料コースの目次だけ見えている状態にすると、動線として強いです。

**注意**：無料コースにワークシートや添削を付けないでください。**無料は「見るだけ」で完結させる**のが線引きの守り方です。

### おすすめの順番

**まずパターンAで3本を配信して、視聴率と個別相談の申込率を見てください。** そのうえで会員サイトに移すと、どのレッスンで離脱するかが分かった状態で設計できます。最初から会員サイトを作り込むと、直しにくくなります。

## スライドの再生成

```bash
npm install pptxgenjs
node build_slides.js
```

- サイズ：`LAYOUT_WIDE`（13.333 × 7.5 inch / 16:9）
- 配色・書体は受講生向け教材と共通（プラム `3E2F38` ／ くすみピンク `C08F97` ／ グレージュ `EAE3DD`）
- **動画用に文字を大きくしています。** 本文は最小18pt、1枚1メッセージ。スマホで見られる前提です
- 受講生向け教材にあった「▶ 心理学の使いどころ」等の実装メモは、意図的に外しています

## 撮影時に守ること

1. **うまくいかない理由を、視聴者の能力のせいにしない。** 「努力が足りない」は言わない。「まだ整っていないだけ」と言う
2. **専門用語を先に説明しない。** 「観念」も、実例を先に出してから名前をつける（動画2のスライド9→10の順番）
3. **個別相談の案内は3本目の最後だけ。** 1本目・2本目では一切触れない
4. **実績や金額の数字を出さない。** 出すと、比較のフィールドに自分から降りることになります
