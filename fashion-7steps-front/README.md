# 無料動画 ― Instagram → LINE 登録者向け

インスタから LINE に登録した方に見せるフロント動画一式です。着地は**個別相談のお申込み**。

受講生向け教材（`../fashion-7steps/`）はそのまま残してあります。

---

## この動画が背負っているもの

インスタのプロフィールで **「ファッション心理学 × AI」** を見て登録された方が相手です。
この2つが**実物として**出てこないと、「またか」で終わります。

| 約束 | 動画での回収の仕方 |
| --- | --- |
| **ファッション心理学** | 観念の実例を出しきったあとに、**「これが、ファッション心理学です」と名前を与える**（スライド10）。先に名乗ると、ただの肩書きになります |
| **AI** | 説明ではなく**実演**。同じお題をAIに2回頼み、出力を並べて見せる（スライド14-18） |

### 実演がこの動画の最大の山です

| | 頼み方 | 出てくるもの |
| --- | --- | --- |
| ① | 「スタイリストのプロフィール文を書いて」 | どこかで見た、当たり障りのない文章 |
| ② | **ファッション心理学の視点（観念・変化）を入れて頼む** | その人にしか書けない文章 |

この対比を見せてから、こう言えます。

> **AIが賢いのではありません。渡す中身を持っている人が、AIを使うと強いんです。**

これで**ファッション心理学とAIが一本の線でつながり**、「だから講座が必要」「だから個別相談で一緒に中身を作る」まで自然に届きます。AIの使い方だけを教える講座との差も、ここで見せられます。

**⚠ 撮影前に必ず：スライド15・16のAI出力は、ご自身で実際に生成してから撮ってください。**
台本の出力例はこちらで作った想定例です。本物を画面で見せるからこそ実演になります。

## 本命は「1本版」（約23分）

**LINE登録直後に、1本で完結させます。**

| ファイル | 内容 |
| --- | --- |
| **`動画台本_1本版.md`** | 本編23分の全文台本。尺配分・テロップ・撮影メモつき |
| **`無料動画スライド_1本版.pptx`** | 全23枚 |
| `LINE配信文.md`（1本版セクション） | 登録直後に動画を渡す文＋フォロー3通 |

### なぜ1本か

1. **登録直後がいちばん熱い。** 「明日届きます」は待ってもらえません
2. **案内に全員が到達する。** 3本に分けると、個別相談の案内が最終回にしか出せません
3. **配信回数が増えるほどブロックされる**

### 構成（23分）

| 経過 | パート | スライド |
| --- | --- | --- |
| 0:00 - 1:00 | つかみ／今日の3つ | 1 - 2 |
| 1:00 - 5:30 | ① なぜ、選ばれないのか | 3 - 6 |
| 5:30 - 12:30 | ② ファッション心理学から見た、本当の理由 | 7 - 13 |
| 12:30 - 17:30 | **③ AIで、今日から変えられること（実演）** ← 山 | 14 - 18 |
| 17:30 - 20:30 | 整えている7つ／現在地チェック | 19 - 21 |
| 20:30 - 23:00 | 個別相談／クロージング | 22 - 23 |

**サムネイルとチャプター名に「AI実演」を入れてください。** これが視聴の理由になります。

## 診断アプリを、登録の入口にする

**動画と競合しません。役割が違います。**

- **診断アプリ ＝ 登録の動機**（軽い・完了率が高い・イメコンの世界と地続き・結果が出るので個別化できる）
- **動画 ＝ 登録後の教育**（なぜ今のままだとうまくいかないか）

```
Instagram → 診断（無料・登録不要で回答）
   → 結果を受け取るために LINE登録
   → ① 結果のひとこと（自動）
   → ② 動画 23分（自動、①の直後）
   → 個別相談
```

### 診断を入口にする利点

1. **登録の心理的ハードルが低い。** 「動画をプレゼント」より「診断できます」のほうが軽い
2. **結果が出るので、次を見る理由が作れる。** 「あなたはこのタイプでした。だから動画の②を特に見てください」と言えると、視聴率が上がります
3. **リストが自動的に分かれる。** 結果別にラベルを付ければ、あとの配信も個別化できます
4. **メタに合っている。** 診断を売っている方に、診断で入っていただく。世界観が一貫します

### 設計のときの注意

- **診断結果は、必ず「痛み」で終わらせず「入口」で終わらせる。** 「あなたは◯◯タイプ。伸ばすには◯番から」と、次の一歩まで書く
- **診断結果と動画の①②③を対応させる。** 結果に応じて「特にここを見てください」と指定できると強い
- **診断の設問に、観念を1問だけ混ぜる。** 「服を買うとき、値段を先に見ますか」のような。これが後半の観念の話への伏線になります

診断アプリの現物を見せていただければ、**結果別の分岐文（LINEの1通目）**と、**結果と動画チャプターの対応表**を作ります。

## 3本版（会員サイトの無料コース用）

**捨てずに残してあります。置く場所が違うと、最適な形も変わるためです。**

| 置き場所 | 形 | 理由 |
| --- | --- | --- |
| LINE登録直後 | **1本（23分）** | 熱があるうちに完結。案内に全員が到達する |
| 会員サイトの無料パート | **3レッスン** | 自分のペースで見る場所。区切りがあったほうが進めやすい |

| ファイル | 内容 |
| --- | --- |
| `動画台本.md` | 3本分の台本（10分・12分・14分）。AI実演とファッション心理学のセリフは1本版を参照 |
| `無料ミニ講座スライド_3本版.pptx` | 全26枚 |

しゅうへいさん方式の一部無料化は、**1本目の動画を見て「もっと知りたい」となった方が潜る場所**として使います。

```
Instagram → 診断 → LINE登録 → 1本版の動画（23分）
   ↓ もっと知りたい方
会員サイトの無料コース（3レッスン）
   ↓
有料コース：6ヶ月実践講座
```

無料コースにワークシートや添削は付けないでください。**無料は「見るだけ」で完結させる**のが線引きの守り方です。

---

## 無料で出すもの／有料に残すもの

| | 内容 |
| --- | --- |
| **無料で出しきる**（＝「なぜ」） | 診断がコモディティ化した理由／診断結果が実行されない理由／観念という考え方／DISCOVERY・AWAKENESS・Circulation の**概念**／「似合う」と「なりたい」のズレ／**AI実演1つ**／7ステップの一覧 |
| **有料に残す**（＝「どうやるか」） | セッションの具体的な質問項目と進め方／商品の3層設計と価格／発信の7つの心理ステップの中身／**AIのプロンプト集と使い分け**／LINE・LP の導線設計／UTAGE・L Message の実装／ワークシートと添削 |

AI実演は**1つだけ**見せます。全部見せると講座に入る理由がなくなり、1つも見せないと「またか」になります。

## スライドの再生成

```bash
npm install pptxgenjs
node build_slides.js     # 1本版・3本版の両方が出力されます
```

- 中身のスライドは1本版・3本版で**共通の関数**から生成しています。文言を直すと両方に反映されます
- サイズ：`LAYOUT_WIDE`（16:9）／配色・書体は受講生向け教材と共通
- 動画用に文字を大きくしています（本文は最小18pt、1枚1メッセージ）

## 撮影時に守ること

1. **AI実演は本物を映す**（台本の出力例をそのまま読まない）
2. **「ファッション心理学」はスライド10まで名乗らない。** 実例を出しきってから名前を与える
3. **うまくいかない理由を、視聴者の能力のせいにしない**
4. **個別相談の案内は終盤だけ**
5. **実績や金額の数字を出さない**
6. **チャプターを設定する**（① 1:00 ／ ② 5:30 ／ **③ AI実演 12:50** ／ 7つ 17:30 ／ 個別相談 20:30）
