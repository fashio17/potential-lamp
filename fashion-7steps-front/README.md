# 無料動画 ― Instagram → LINE 登録者向け

インスタから LINE に登録した方に見せるフロント動画一式です。着地は**個別相談のお申込み**。

受講生向け教材（`../fashion-7steps/`）はそのまま残してあります。**同じ7ステップを扱いますが、役割が逆です。**

| | 受講生向け教材 | この無料動画 |
| --- | --- | --- |
| 相手 | 入会済みの受講生 | まだ何も買っていない人 |
| 話すこと | **どうやるか**（実装） | **なぜ今のままだとうまくいかないのか**（原因） |
| 7ステップ | あなたがやる7つ（行動計画） | 選ばれている人が整っている7つ（**地図**） |
| ワーク | ワークシート・宿題あり | なし（チェック4問のみ） |

## 本命は「1本版」（22分）

**LINE登録直後に、1本で完結させます。**

| ファイル | 内容 |
| --- | --- |
| **`動画台本_1本版.md`** | 本編22分の全文台本。尺配分・テロップ・撮影メモつき |
| **`無料動画スライド_1本版.pptx`** | 全19枚 |
| `LINE配信文.md`（1本版セクション） | 登録直後に動画を渡す文＋フォロー3通 |

### なぜ1本か

1. **登録直後がいちばん熱い。** 24時間後には下がります。「明日届きます」は待ってもらえません
2. **案内に全員が到達する。** 3本に分けると、個別相談の案内が最終回にしか出せず、途中離脱した方には一生届きません
3. **配信回数が増えるほどブロックされる。** 上品さと信頼感が資産のブランドでは、ここは特に守りたいところです

### 内容は削っていません

34分 → 22分にしたのは、**分割していたせいで発生していた冗長部分**を外しただけです。

- 次回予告（2回）
- 各回の冒頭の振り返り
- 「これは意志の問題ではありません」（次回への引き伸ばし用だったスライド）

診断のコモディティ化も、観念も、DISCOVERY→AWAKENESS→Circulation も、「似合う」と「なりたい」のズレも、全部残っています。

**捨てずに残してあります。置く場所が違うと、最適な形も変わるためです。**

### しゅうへいさん方式（スクールサイトの一部無料化）の位置づけ

**1本目の動画を見て「もっと知りたい」となった方が潜る場所**として、会員サイトの無料コースを置きます。

```
Instagram → LINE登録
   ↓（登録直後）
1本版の動画（22分）
   ↓ もっと知りたい方
会員サイトの無料コース（3レッスン）
   ↓
有料コース：6ヶ月実践講座
```

無料コースの下に有料コースの目次だけ見えている状態にすると、動線として強くなります。
**ただし無料コースにワークシートや添削は付けないでください。** 無料は「見るだけ」で完結させるのが線引きの守り方です。

## 無料で出すもの／有料に残すもの

**この線引きが、この設計のいちばん大事なところです。**

| | 内容 |
| --- | --- |
| **無料で出しきる**（＝「なぜ」） | 診断がコモディティ化した理由／「診断ができます」が機能しない理由／診断結果が実行されない理由／観念という考え方／DISCOVERY・AWAKENESS・Circulation の**概念**／「似合う」と「なりたい」のズレ／7ステップの**一覧**（各1行） |
| **有料に残す**（＝「どうやるか」） | セッションの具体的な質問項目と進め方／商品の3層設計と価格／発信の7つの心理ステップの中身／LINE・LP の導線設計／UTAGE・L Message の実装／ワークシートと添削 |

出し惜しみすると、よくある集客動画になります。逆に「どうやるか」まで出すと、講座に入る理由がなくなります。**「なぜ」は全部出す。「どうやるか」は出さない。**

## スライドの再生成

```bash
npm install pptxgenjs
node build_slides.js     # 1本版・3本版の両方が出力されます
```

- 中身のスライドは1本版・3本版で**共通の関数**から生成しています。文言を直すと両方に反映されます
- サイズ：`LAYOUT_WIDE`（13.333 × 7.5 inch / 16:9）
- 配色・書体は受講生向け教材と共通（プラム `3E2F38` ／ くすみピンク `C08F97` ／ グレージュ `EAE3DD`）
- **動画用に文字を大きくしています。** 本文は最小18pt、1枚1メッセージ

## 撮影時に守ること

1. **うまくいかない理由を、視聴者の能力のせいにしない。** 「努力が足りない」は言わない
2. **専門用語を先に説明しない。** 「観念」も、実例を先に出してから名前をつける
3. **個別相談の案内は終盤だけ。** 途中で匂わせない
4. **実績や金額の数字を出さない**
5. **22分あるので、チャプターを必ず設定する**（① 1:00 ／ ② 6:30 ／ ③ 14:40 ／ 個別相談 21:00）
