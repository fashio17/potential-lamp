# Instagram アカウント差分分析 — @eriko.fashionlabo

対象アカウント: [松岡依里子 えりりん ファッション起業プロデューサー (@eriko.fashionlabo)](https://www.instagram.com/eriko.fashionlabo/)

## このディレクトリの目的

アカウントの状態を定期的にスナップショットとして記録し、時点間の**差分(フォロワー数の増減、投稿の追加、bio・プロフィールの変更、エンゲージメントの変化など)**を分析するためのものです。

## 運用方法

1. `snapshots/YYYY-MM-DD.md` をコピーして新しい日付のファイルを作成する
2. Instagramアプリの「プロフェッショナルダッシュボード(インサイト)」やプロフィール画面から各項目を転記する
   - スクリーンショットやインサイトのデータをそのまま渡してもらえれば、Claudeが転記・整形します
3. スナップショットが2件以上たまったら、差分分析レポートを `diff-reports/` に作成する

## 差分分析で見る項目

| 項目 | 差分の意味 |
|------|-----------|
| フォロワー数 | 増減数・増減率(成長トレンド) |
| 投稿数 | 新規投稿の頻度 |
| フォロー数 | フォロー戦略の変化 |
| bio・名前・リンク | ブランディング/導線の変更 |
| 投稿ごとのいいね・コメント・保存 | エンゲージメント率の推移、伸びた投稿の特徴 |
| リーチ・プロフィールアクセス(インサイト) | 認知の広がり、導線の効果 |

## 注意事項

- この分析環境からはInstagramへの直接アクセスがネットワークポリシーによりブロックされているため、データはユーザー提供(スクリーンショット、インサイトのエクスポート、手入力)が必要です。
