# ファッション起業 7つのステップ

未経験〜立ち上げ1年目の方に向けた、60分セミナー用の台本とスライド一式です。

## 成果物

| ファイル | 内容 |
| --- | --- |
| `台本.md` | 60分セミナーの完全台本。タイムテーブル、スライド別のセリフ・狙い・演出メモ、想定Q&A、配布用ワークシート項目、進行のコツ |
| `ファッション起業7つのステップ.pptx` | スライド全22枚（16:9 ワイド）。全スライドにスピーカーノート付き |
| `build_slides.js` | スライドの生成スクリプト（pptxgenjs） |

## スライド構成（全22枚）

| # | 内容 |
| --- | --- |
| 1 | 表紙 |
| 2 | 今日のゴール |
| 3 | 7ステップの全体像 |
| 4 | よくあるつまずき3パターン |
| 5-6 | STEP1 コンセプト設計（誰に・何を・なぜ） |
| 7-8 | STEP2 市場と顧客のリサーチ（3C＋ポジショニングマップ） |
| 9-10 | STEP3 商品企画とラインナップ設計（1型スタート／3つの役割） |
| 11-12 | STEP4 生産と仕入れ（4つの作り方の比較表） |
| 13-14 | STEP5 価格設計と収支計画（逆算・内訳・損益分岐点） |
| 15-16 | STEP6 販売チャネルの構築 |
| 17-18 | STEP7 ブランディングと集客（4段階） |
| 19 | まとめ：7つのステップ |
| 20 | 90日ロードマップ |
| 21 | 明日からの3つの宿題 |
| 22 | クロージング／質疑応答 |

奇数番号の扉スライド（5・7・9・11・13・15・17）が各STEPの区切りです。時間が押した場合は
スライド4 →スライド20 の順に削り、スライド21（宿題）は残してください。

## 数字の扱い

スライド14の売値・原価率・原価などの数値は、**計算方法を示すための例**です。実際に登壇する際は
ご自身の商材の数字に置き換えてください。断定的な市場統計は含めていません。

## スライドの再生成

内容や配色を変更する場合は `build_slides.js` を編集して再生成します。

```bash
npm install pptxgenjs
node build_slides.js
```

- サイズ：`LAYOUT_WIDE`（13.333 × 7.5 inch / 16:9）
- 配色：ベリー `6D2E46` ／ ダスティローズ `A26769` ／ クリーム `ECE2D0`
- 書体：見出し「Yu Mincho」、本文「Yu Gothic」
