# スマホからClaude Codeを使えるようにする手順書

別のデバイス・別のClaudeアカウントで、同じ環境をゼロから構築するための手順です。
PCへのインストールは**不要**。スマホとブラウザだけで完結します。

---

## 0. 最初に理解しておくこと

Claude Codeは、スマホの中で動くわけではありません。

```
  スマホ（リモコン）
        ↓ チャットで指示
  クラウドVM（Anthropic管理のLinux・使い捨て）  ← 実際の作業はここ
        ↓ clone / push
  GitHub（倉庫・永続）                          ← 成果物はここに残る
```

- **VM** = 作業机。使わないと回収される。中のファイルは消える
- **GitHub** = 金庫。`git push` したものは永続的に残る
- **会話履歴** = Anthropic側に保存され、VMが消えても残る

> **唯一の鉄則：pushしていないものは消える。**
> 作業の区切りごとに「コミットしてpushして」と伝えれば安全です。

VMは常に同じLinux環境なので、**接続元がMacでもWindowsでもiPhoneでもAndroidでも、まったく同じ環境**が立ち上がります。機種による差はありません。

## 1. 人間がやる作業（所要 15〜20分）

以下はClaude Codeに依頼できません。認証やアプリインストールは本人がGUIで行う必要があります。

### ステップ1：Claudeの有料プランに加入

- **Pro / Max / Team / Enterprise のいずれかが必須**
- **無料プランではClaude Codeは使えません**（ここでつまずく人が最多）
- 加入先：https://claude.ai/upgrade

### ステップ2：GitHubアカウントを用意

- 既存のものでも新規でも可：https://github.com
- **重要**：ここで連携したGitHubアカウントが見えるリポジトリすべてに、クラウドセッションからアクセスできるようになります。仕事用と私用を分けたい場合は、この時点でどちらを繋ぐか決めてください

### ステップ3：ブラウザでGitHubを連携（★ここが設定の本体）

スマホのブラウザでも可能ですが、**初回はPCのブラウザ推奨**（認可画面が操作しやすいため）。

1. https://claude.ai/code を開く
2. Claudeアカウントでログイン
3. オンボーディング画面で **「Connect GitHub」** を選択
4. **Claude GitHub App** の認可画面が出るので承認
5. 対象リポジトリを選択（All repositories / 特定のリポジトリを選択）

> 💡 GitHub Appを入れておくと、後で「PRのCI失敗やレビューコメントに自動対応」（Auto-fix）も使えるようになります。

### ステップ4：Claudeモバイルアプリを入れる

- iOS：App Store で「Claude」
- Android：Google Play で「Claude」
- **ステップ1〜3と同じClaudeアカウントでログイン**（別アカウントだとセッションが見えません）

### ステップ5：最初のセッションを起動して動作確認

1. モバイルアプリまたはスマホのブラウザで claude.ai/code を開く
2. リポジトリを選択
3. 試しにこう投げてみる：

   ```
   このリポジトリの構成を教えて
   ```

4. 応答が返ってくれば設定完了 ✅

## 2. 動作確認：Claude Codeに投げるプロンプト

セッションが立ち上がったら、以下をそのままコピペして送ってください。
接続状態の検証と、以降の運用ルールの共有を一度に行います。

```
このセッションのセットアップが正しく完了しているか確認してください。

【確認してほしいこと】
1. どのリポジトリがクローンされているか（git remote -v）
2. いまどのブランチにいるか、リモートと同期しているか
3. 未コミット・未pushの変更が残っていないか
4. VMのスペック（OS / CPU / メモリ）
5. GitHubへの読み書きが実際にできる状態か

【結果の報告方法】
専門用語は避けて、初心者にもわかるように説明してください。
問題があれば、何が原因でどう直せばいいかもセットで教えてください。

【以降の運用ルール】
- 作業が一区切りついたら、指示がなくてもコミットしてpushしてください
  （VMは放置すると回収され、pushしていない変更は失われるため）
- pushが完了したら「保存完了」と明示的に伝えてください
- 破壊的な操作（ファイル削除、履歴の書き換え、force push）の前は
  必ず確認を取ってください
```

### 補足：CLAUDE.md を置いておくと毎回説明しなくて済む

リポジトリのルートに `CLAUDE.md` を置くと、その内容がセッション開始時に自動で読み込まれます。上記の「運用ルール」を書いておけば、毎回貼り付ける必要がなくなります。

Claude Codeにこう頼めば作ってくれます：

```
このリポジトリのルートに CLAUDE.md を作ってください。
内容は「作業の区切りごとに自動でコミット＆pushする」
「破壊的操作の前は確認を取る」というルールにしてください。
```

## 3. PCの設定について（今はやらない）

### 結論：ThinkPadには何もインストールしないでください

近くMacに移行する予定であれば、**今PCに設定する作業はすべて無駄になります**。

| | 設定の単位 | 機種変更したら |
|---|---|---|
| **モバイル/Web設定**（第1章） | **アカウント単位** | そのまま使える。再設定不要 |
| **CLIインストール** | **マシン単位** | 新しいマシンで入れ直し |

第1章の設定はClaudeアカウントとGitHubアカウントの紐付けなので、PCを買い替えても影響を受けません。**先にモバイル設定だけ済ませておくのが正解**です。

### データ移行の心配も不要

成果物はすべてGitHubにあります。ThinkPadのローカルには何も溜まりません。Macを買ったら `git clone` するだけで、過去の作業が全部そこに現れます。

### Mac入手後にやること（所要5分）

そのときになったら、以下を実行するだけです。

```bash
# 1. インストール
curl -fsSL https://claude.ai/install.sh | bash

# 2. 起動（ブラウザが開くのでモバイルと同じアカウントでログイン）
claude

# 3. 確認
claude --version
```

Homebrewを使うなら `brew install --cask claude-code` でも可。
GUIで使いたい場合はデスクトップアプリ版もあります。

インストール後に使えるようになる主な機能：

| コマンド | できること |
|---|---|
| `claude --teleport` | スマホで進めたセッションを、会話履歴ごとMacのターミナルに引き継ぐ |
| `claude --cloud "指示"` | Macからクラウドセッションを起動して、放置したまま外出する |
| `/tasks` | 走っているセッションの一覧を見る |

**この章は、Macが手元に来てから着手すれば十分です。**

## 4. つまずきポイント early warning

| 症状 | 原因 | 対処 |
|---|---|---|
| Claude Codeのメニューが出てこない | 無料プランを使っている | Pro以上に加入する |
| モバイルアプリにセッションが出ない | 別のClaudeアカウントでログインしている | 同一アカウントでログインし直す |
| リポジトリが選択肢に出ない | GitHub連携で対象に含めていない | GitHub App の設定でリポジトリを追加 |
| 「Session creation failed」 | VMの割り当て一時失敗 | 1分待って再試行。https://status.claude.com も確認 |
| 「expired」と表示された | 放置でVMが回収された | セッションを開き直せば新しいVMで復元される（正常動作） |
| 作業内容が消えた | pushしていなかった | 予防策：区切りごとにpushを習慣化 |

## 5. 1分でわかる要約

1. **Claude有料プランに入る**（無料プラン不可）
2. **claude.ai/code でGitHubを連携する**（設定の本体はここだけ）
3. **モバイルアプリを入れて同じアカウントでログインする**
4. **PCへのインストールは、Macが来てからでよい**
5. **区切りごとにpushする**（これだけ守れば何も失われない）
