# 旅費積算案（令和9年度＝1年目に集中／周回渡航）

研究期間中の海外渡航は**1年目の1回のみ**。2・3年目は国内実験とオンライン調査で完結する。
行程は前年度と同様の**周回渡航**：成田 → パリ → ミラノ → ロンドン → ニューヨーク → 成田（計18日・16泊・1名）

## 目的
- **パリ・ミラノ・ロンドン**：実施済みパリ調査と同一手続の半構造化インタビュー＋生成AI診断の即時提示（各都市10名程度）。モードの発信地ミラノ、多文化・古着文化のロンドンを加え、欧州内部の多様性を捉える。
- **ニューヨーク**：FIT（Fashion Institute of Technology）教員との研究打ち合わせ、質的調査の補足、以後の国際連携の基盤形成。

## 積算

| 費目 | 内訳 | 金額（円） |
|---|---|---|
| 航空賃 | 周回航空券（成田→パリ／ロンドン→NY→成田、燃油・空港使用料込） | 430,000 |
| 都市間移動 | パリ⇄ミラノ⇄ロンドン（高速鉄道／域内航空） | 45,000 |
| 宿泊費 | 欧州 20,000円 × 10泊 ＝ 200,000／NY 25,000円 × 6泊 ＝ 150,000 | 350,000 |
| 日当 | 4,000円 × 18日 | 72,000 |
| 現地交通費 | 各都市の市内交通 | 35,000 |
| 海外旅行保険 | 18日・1名 | 25,000 |
| **合計** | | **957,000** |

## **合計：約96万円**（令和9年度に計上）

### 個別渡航案との比較
| 方式 | 概算 | 差 |
|---|---|---|
| 個別渡航（欧州12日＋NY7日の2回） | 約115万円 | — |
| **周回渡航（18日・1回）** | **約96万円** | **▲約19万円** |

周回により航空賃を圧縮できる一方、不在期間が約18日と長くなるため、授業期間を避けた日程調整が必要。

## 注記
- 単価は目安。所属機関（東京家政大学）の旅費規程に合わせて日当・宿泊上限を調整すること。可能なら代理店見積を1点取得。
- **経費配分の考え方**：基盤C（3年総額 約450〜500万円）のうち、1年目に旅費を集中させ、2年目は調査委託費・謝金（大学生600名調査＋授業実践240名）、3年目は翻訳・オンライン調査・成果公開に充てる。
- 逐語化・翻訳の委託費は「人件費・謝金」費目に別途計上。
- 3年目のアジア確認調査は、台湾は協力大学経由で渡航不要。韓国は調整が整わない場合、現地調査会社のパネル委託（渡航不要）で代替する。
