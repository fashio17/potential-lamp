# １ 研究目的、研究方法など（4頁以内）

## （概要）

本研究は、装いから生じる心理的安定感（Fashion-based Psychological Stability: FPS）が、文化的な「似合う」規範、ファストファッション環境、AIによる助言の下でどのように形成されるかを解明する。科研費開始前のR8年度に日本・台湾・韓国の学生を対象とする比較オンライン調査を完了し、その共通尺度と知見を基盤とする。R9年度はミラノ・パリで学生を中心とした質的調査と大学への協力依頼を行い、タイの国際学会で東アジア比較の成果を発表する。R10年度は、イタリア・フランス・米国・オーストラリアの学生各200名、計800名を対象とする多言語オンライン調査を実施する。併せて、IFHE（ニュージーランド）で欧州質的調査の成果を発表し、これと接続してパースのCurtin Universityを訪問し、さらにニューヨーク（FIT）で協力依頼と補足ヒアリングを行う。R11年度はR8・R10のデータを統合した7カ国データベースを基に、日本の大学生を対象とする教育介入と生成AI活用実験を統合した2×2要因計画を実施する。文化比較から教育実装までを3年間で完結させ、次期科研費のAI活用研究へ接続する。

## （本文）

### (1) 本研究の学術的背景や本研究の着想に至った経緯、研究課題の核心をなす学術的「問い」

現代の若者の装いは、選択の自由が拡大する一方、SNS、パーソナルカラー・骨格診断、生成AI、ファストファッションの高頻度な商品・情報更新によって、絶えず「似合う正解」を求められる状況にある。ラグジュアリーとファッション教育の集積地であるミラノ・パリ、世界最大級の多文化消費市場でありファッション教育の中心地（FIT等）でもあるニューヨーク、アジア太平洋圏の英語圏消費市場であるパースは、「似合う」規範の形成と受容を比較する上で異なる文化的・産業的条件を持つ。もっとも本研究の主対象は企業ではなく大学生であり、教員・実務家への面接は、学生が受け取るメッセージの生成側を理解するための補足資料とする。

本研究の核心をなす問いは、**「同じ装い情報やAI助言が、なぜある学生には自己理解と心理的安定の資源となり、別の学生には外部規範への従属と不安をもたらすのか。その分岐は文化と教育によってどのように変化するか」**である。自己決定理論（Self-Determination Theory: Deci & Ryan, 2000）に基づけば、外部情報は自律的に内在化されると有能感とFPSを高めるが、統制的に受容されると自律性を損なう。本研究は、東アジア3カ国と欧米豪4カ国の比較、質的調査、教育・AI実験を接続し、この分岐の文化差と介入可能性を検証する。

申請者は、ジェンダーと着装行動、ワードローブ、感性価値、SNSと自己表現を継続的に研究してきた。2026年の予備調査（パーソナルスタイリング受講者N=127）では、似合い知覚（SP: M=5.64, α=.92）、FPS（M=6.44, α=.81）、受講後の肯定的変化（M=6.00, α=.91）が高水準を示し、受講前後でSP（2.84→5.60, t=21.31, p<.001）とFPS（4.93→6.42, t=12.02, p<.001）が上昇した。この結果は「似合う」情報が適切に内在化された場合、心理的安定と行動変容を促す可能性を示す。さらにR8年度中に科研費申請補助資金により日・台・韓の学生比較を完了し、大学院研究推進費（特別研究費）によりフランス・ニューヨークの研究基盤の構築に着手しており、文化比較に用いる共通尺度と運用手順、欧米展開の足場を科研費開始前に確立する。

一方、既存の予備調査は中年女性に偏り、若年層・男性・文化差を十分に扱えていない。また、量的関連が確認されても、学生がどの語りや経験を通して装い情報を自律的または統制的に受容するかは明らかでない。そこでR9年度の欧州質的調査で文化固有の語彙と仮説を形成し、R10年度の4カ国オンライン調査で一般化可能性を検証し、R11年度の教育・AI実験で因果的に検証する。

### (2) 本研究の目的および学術的独自性と創造性

本研究の目的は、FPSと装いの自己決定の関係を国際比較によって構造化し、教育およびAI活用の効果を実証することである。具体的には以下の5点である。

1. R8年度の日・台・韓比較データを再分析し、東アジアの基準モデルを確立する。
2. ミラノ・パリの質的調査から、文化固有の「似合う」規範、ファストファッション、AI助言の受容過程を抽出する。
3. イタリア・フランス・米国・オーストラリアの4カ国オンライン調査により、FPS尺度の測定不変性と構造差を検証する。
4. R8・R10のデータを統合した7カ国データベースを構築する。
5. 日本の大学生に対する教育介入とAI活用実験により、FPS・装い自律性・意思決定の質への効果を検証する。

**学術的独自性**は3点ある。第一に、東アジアと欧米豪を別々に調べるのではなく、R8年度の既存データと科研費期間中の新規データを共通尺度で接続し、7カ国比較へ発展させる点である。第二に、学生の受容過程を中心に据えつつ、大学教員・ファッション実務家への補足面接により規範の生成側も捉え、量的比較の解釈可能性を高める点である。第三に、生成AIを単なる調査道具ではなく、装いの自律性を支援も阻害もする介入要因として実験的に扱う点である。

**創造性**は、被服心理学、自己決定理論、ファッション教育、AI助言研究を「装いのウェルビーイング」という一つの枠組みで結ぶ点にある。国際比較データから教育内容を設計し、その介入効果とAI利用の交互作用を同一研究内で検証することで、記述的な文化比較を教育実装へと転換する。

### (3) 関連分野の研究動向と本研究の位置づけ

ファッション心理学では、服装と自己概念の一致、Enclothed Cognition、外見規範が気分・認知・自己効力感に及ぼす影響が論じられてきた。しかし、日常的な装いがもたらす恒常的な心理的安定、文化固有の「似合う」判断、ファストファッション環境とAI助言の影響を、文化比較から教育介入まで連続して検証した研究は少ない。自己決定理論は外部規範の内在化の質を説明できるが、装いの意思決定への適用は限定的である。本研究は、質的調査で文化的意味を把握し、測定不変性を確認した国際比較で構造差を検証し、介入実験で因果性を確かめる混合研究法により、この空白を埋める。

### (4) 本研究で何をどのように、どこまで明らかにしようとするのか（研究方法と研究デザイン）

本研究は3年間・3段階で構成する。科研費開始前のR8年度に完了する日・台・韓比較調査を基盤データとし、R9年度の質的仮説生成、R10年度の欧米豪量的検証、R11年度の教育・AI実験へ順次接続する。対象国は無制限に増やすのではなく、各地域の比較上の役割と、**すべての調査地に具体的な人的経路が存在すること**を基準に選定した（ミラノ＝申請者の元指導学生、パリ＝大学院研究推進費により開拓中、ニューヨーク＝FITの研究者との人的接点、パース＝Curtin Universityとの交流実績、日台韓＝R8調査の協力大学）。

**科研費開始前（R8年度）：日・台・韓比較調査の完了と欧米展開の足場づくり**

科研費申請補助資金により、日本・台湾・韓国の学生を対象とするオンライン比較調査を年度内に完了する。FPS、SP（似合い知覚）、装い自律性、WDQI（ワードローブ意思決定の質）、SNS・AI診断利用等の共通項目を用い、翻訳・逆翻訳、データクリーニング、基礎的な測定不変性の確認を行う。並行して、大学院研究推進費（特別研究費）によりフランス・ニューヨークとの研究連携の基盤構築を進める。R9年度にはアジア比較の成果をタイの国際学会で発表し、科研費で取得する4カ国データと比較できる基準データとして整備する。

**Step1（R9年度）：欧州2都市の質的調査と国際比較仮説の精緻化**

ミラノ、パリの大学・ファッション教育機関を訪問し、学生を中心に各都市12〜15名程度、合計約30名を目安として半構造化面接を行う。主題は、①「似合う」の意味、②装い情報の自律的／統制的受容、③ファストファッションとサステナビリティ、④SNS・生成AIによる助言、⑤装いと心理的安定である。ミラノは元指導学生の人脈により協力大学を先行確定し、訪問時にオンライン調査の実施体制まで合意する。パリは本訪問で協力先を開拓・確定する。大学教員・実務家への面接を補足的に実施する。逐語録をテーマ分析とKHコーダーで分析し、R10調査の質問項目・文化仮説・表現妥当性を確定する。あわせて、タイで開催されるアジア地域国際学会（ARAHE等【要確認】）で日・台・韓比較の成果を発表する。

**Step2（R10年度）：4カ国オンライン調査と現地連携の確立**

イタリア、フランス、米国、オーストラリアの18〜29歳の学生を対象に、各国N=200（男女等の属性を可能な範囲で均衡）、計N=800の多言語オンライン調査を行う。協力大学からの募集を基本とし、不足分は国際パネルで補完して標本源を統制変数として扱う。MG-CFAにより配置・弱・強不変性を検証した後、規範内在化→装い自律性→FPS→ウェルビーイングの構造差、ジェンダー差、ファストファッション・AI助言利用の調整効果を分析する。

R9の質的成果をIFHE（ニュージーランド【要確認：正式日程】）で発表し、同時期にパースのCurtin Universityを訪問して学生調査の協力依頼と教員・学生ヒアリングを行う（ニュージーランド→パースの連続渡航により経費を圧縮。訪問が困難な場合はオンライン会議で代替可能な関係性を先行構築する）。さらにニューヨークを訪問し、FITの研究者を起点に学生調査の協力体制を確立するとともに、ファッション教育・消費文化に関する補足ヒアリングを行う。

**Step3（R11年度）：7カ国データベースに基づく教育介入・AI実験**

R8年度の日・台・韓データとR10年度の4カ国データを統合し、尺度対応表、翻訳履歴、匿名化データ、分析コードからなる7カ国比較データベースを構築する。その知見に基づき、日本の大学生N=240を対象に、教育モジュール（実施／待機統制）×AI支援（生成AIによる選択支援／従来型ワークシート）の2×2要因計画（各群約60名）を実施する。事前・事後・1か月後にFPS、装い自律性、WDQI、自己効力感、購買後悔を測定し、混合効果モデルで主効果・交互作用・持続性を検証する。AI条件では、個人を特定する画像・属性を学習用途に提供せず、研究用に標準化した指示と選択肢を用いる。最終年度に尺度、教育教材、分析結果を報告書・学会・論文で公表し、文化適応型AI支援を主題とする次期科研費へ発展させる。

**役割分担**：研究代表者・松岡依里子は研究総括、国際連携、質的調査、教育モジュール設計、成果統合を担う。研究分担者・石井国雄は自己決定・ジェンダー理論、2×2実験計画、測定不変性・混合効果モデルを担当する。研究分担者・内藤章江は多国間質問紙の運用、データ管理、SEM分析を担当する。研究協力者・五月女由紀子はSNS・生成AI・ファストファッション行動の項目設計に助言する。海外協力先は、R8の日・台・韓協力大学に加え、ミラノ、パリ、FIT（ニューヨーク）、Curtin University（パース）の大学・教育機関とし、各協力者名は内諾取得後に確定する。

### (5) 本研究の目的を達成するための準備状況

本研究は、R8年度に完了する日・台・韓比較調査、大学院研究推進費によるフランス・ニューヨークの基盤構築、既存の予備調査、過去の海外調査経験を基盤とし、R9年度から直ちに開始できる。

1. **予備調査と尺度候補**：パーソナルスタイリング受講者N=127の調査を完了し、SP・FPSの信頼性と受講前後差を確認した。尺度候補項目、分析環境（SPSS/Amos・R、KHコーダー）、教育効果測定の経験を有する。
2. **R8年度の日・台・韓比較**：科研費申請補助資金を活用し、3カ国の学生オンライン調査を年度内に完了する。翻訳・逆翻訳、募集手順、国際データ管理を科研費開始前に経験し、R9年度にタイで成果を国際発表する。

4. **欧州質的調査の準備**：ミラノには申請者の元指導学生を含む人的接点があり、協力大学を先行確定できる。パリではファッション教育機関との調査経験を活用できる。

# ３ 人権の保護及び法令等の遵守への対応

本研究では、海外での半構造化面接、多国間オンライン調査、日本での教育介入・AI実験を行うため、東京家政大学倫理審査委員会の承認を得た後、各協力機関の規程と各国法令に従って実施する。R8年度調査のデータを科研費研究で二次利用する場合は、当初の同意範囲を確認し、必要に応じて変更申請または再同意を行う。

**【研究における倫理的配慮】**

1. **個人情報と研究データ**：氏名・学籍番号を分析データから分離し、研究IDで管理する。協力大学の教員が募集に関与する場合も、参加の有無が成績・指導・評価に影響しないことを明示する。録音データ、逐語録、オンライン回答、分析用データはアクセス権を限定し、所属機関の規程に従って保管する。
2. **インフォームド・コンセント**：研究目的、任意参加、撤回可能性、録音・引用方法、データ保管期間、国際共同研究での利用範囲を各言語で説明する。オンライン調査では説明画面で同意した者のみ回答へ進み、面接調査では文書同意を得る。
3. **国際調査**：EU圏（イタリア・フランス）はGDPR、米国は協力機関（FIT等）のIRB・プライバシー規程、オーストラリアは現地機関の規程と調査会社のプライバシー基準に準拠する。翻訳・逆翻訳を経た説明文書・質問紙を用い、国外移転の有無、保存場所、再利用範囲を明示する。
4. **AI実験**：AI条件では個人を特定できる顔画像、氏名、学籍番号、健康情報等を外部サービスへ入力しない。研究用に標準化したプロンプトと選択情報を使用し、出力の誤り・偏見・規範的表現の可能性を事前説明する。AIの出力は診断や評価ではなく意思決定支援であり、研究者が安全性を確認した範囲で提示する。教員・実務家への面接では、営業秘密や個人情報の提供を求めない。
5. **保存・破棄と公開**：対応表と生データを分離して保存し、保存期間終了後に復元不可能な方法で破棄する。公開する7カ国データベースは個人が再識別されない集計値または匿名化データとし、少数セル、自由記述、逐語録の公開範囲を制限する。
