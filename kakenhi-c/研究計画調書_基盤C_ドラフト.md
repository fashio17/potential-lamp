# １ 研究目的、研究方法など（3頁以内）

## （概要）

本研究の目的は、ファストファッションのグローバルな普及のもとで、大学生の衣服の購買・使用・廃棄行動と持続可能性意識（環境配慮・労働倫理・資源循環）が文化圏によってどのように異なるのかを、日本・台湾・韓国（令和8年度学内研究費により調査済み）に、イタリア（ミラノ）、フランス（パリ）、オーストラリア（パース）、北欧（スウェーデンまたはノルウェー）を加えた国際比較オンライン調査によって実証的に解明することである。あわせて、ファッションの生産・発信拠点である欧州の大学および企業関係者への質的調査により、各国の衣生活教育・消費文化の背景要因を把握する。最終年度には、構築した国際比較データベースに基づき、日本の大学生を対象とする持続可能な衣生活教育プログラムを開発し、生成AIを活用した学習支援実験と組み合わせて教育介入効果を検証する。以上により、国際的な視野に立った衣生活消費者教育のモデルを提示する。

## （本文）

### (1) 本研究の学術的背景、研究課題の核心をなす学術的「問い」

**① 学術的背景**

ファストファッションの世界的普及は、衣服の低価格化・大量消費・大量廃棄を加速させ、繊維産業はいまや世界の温室効果ガス排出・水質汚染・労働問題の主要因の一つとされる（【要確認：引用データの確定。例：UNEP, Ellen MacArthur Foundation報告等】）。これを受けて欧州では、EUのサステナブル・循環型繊維戦略（2022）など制度的対応が進み、消費者教育・衣生活教育の再構築が国際的課題となっている。

一方、衣服消費行動研究においては、「持続可能性への態度は高いが行動が伴わない」という態度－行動ギャップ（attitude-behaviour gap）が繰り返し指摘されてきた（【要確認：引用文献】）。このギャップの現れ方は、各国の消費文化、ファッション産業構造、学校教育における衣生活教育の位置づけによって異なると考えられるが、アジアと欧州・オセアニアを共通の枠組みで比較した実証研究は僅少である。特に、H&Mを擁する北欧、ラグジュアリーとファストファッションが併存するイタリア・フランス、消費市場としてのオーストラリアと、生産・消費の両面でファストファッションの影響を強く受ける東アジアとを横断する比較は、国際的にもほとんど行われていない。

応募者は約20年間、大学においてファッション分野の人材育成と被服学・衣生活教育の研究に従事し、オーストラリア（カーティン大学：12年前に訪問調査）およびノルウェー（10年前に調査実施）での海外調査経験を有する（研究業績『オーストラリアのファッション教育―アクティブラーニングからエンゲージドラーニングへ』ほか【要確認：書誌情報】）。さらに令和8（2026）年度には、学内研究費により日本・台湾・韓国の大学生を対象とするファストファッション消費行動のオンライン比較調査を完了する予定であり、アジア圏のベースラインデータを確保している。

**② 核心をなす学術的「問い」**

> ファストファッションがグローバルに均質な消費環境をもたらすなかで、大学生の衣服消費行動と持続可能性意識はなぜ、どのように文化圏によって異なるのか。そして、その差異の要因を組み込んだ教育介入は、日本の大学生の衣服消費行動を変容させうるのか。

この問いは、①消費行動の規定要因（文化・産業構造・教育）の国際比較という記述的・説明的問いと、②比較知見に基づく教育介入の有効性検証という実践的問いの二層からなる。

### (2) 本研究の目的および学術的独自性と創造性

**① 目的**

本研究は、研究期間内に以下の3点を明らかにする。

- **目的1（国際比較）**：アジア3カ国（日本・台湾・韓国：調査済み）と欧米4地域（イタリア・ミラノ、フランス・パリ、オーストラリア・パース、北欧：スウェーデンまたはノルウェー）の大学生を対象とする共通設計のオンライン質問紙調査により、衣服の購買・使用・廃棄行動、持続可能性意識、衣生活教育経験の異同を定量的に解明し、7カ国・地域の国際比較データベースを構築する。
- **目的2（背景要因の質的解明）**：欧州・オセアニアの大学教員・学生およびファストファッション企業関係者（H&M等【要確認：交渉状況に応じて記載】）への訪問インタビューにより、量的差異の背景にある消費文化・産業構造・教育制度の要因を質的に解明する。
- **目的3（教育介入の開発と検証）**：目的1・2の知見を統合し、日本の大学生向けの持続可能な衣生活教育プログラムを開発する。生成AIを活用した学習支援（例：AIとの対話による自己の消費行動の振り返り・意思決定支援【要確認：実験デザインの確定】）を組み込み、事前事後測定により介入効果を検証する。

**② 学術的独自性と創造性**

- **比較の独自性**：東アジア（生産・消費の急拡大圏）、南欧（ファッション文化の発信地：ミラノ・パリ）、北欧（H&Mの本国でありサステナビリティ先進圏）、オセアニア（英語圏消費市場）という性格の異なる文化圏を、同一の調査設計で比較する初の試みである。
- **方法の独自性**：現地の協力大学を介したオンライン調査（量的）と、大学・企業への訪問調査（質的）を組み合わせる混合研究法により、「差異の記述」にとどまらず「差異の説明」まで踏み込む。
- **実践への創造性**：国際比較の知見を日本の教育介入に還流させ、さらに生成AIを学習支援に活用する点に創造性がある。本研究のAI活用実験は、次期研究課題（AIを本格活用した衣生活教育研究）への基盤となる。

**【令和11年度】統合分析と教育介入・AI実験**

- アジア3カ国＋欧米4地域の計7カ国・地域データベースを統合し、多母集団同時分析等により、衣服消費行動・持続可能性意識の文化圏間差異とその規定要因（教育経験・産業構造・価値観）を解明する。
- 国際比較の知見（例：各国の廃棄抑制行動、リユース文化、教育経験の効果）を教材化し、日本の大学生を対象とする**持続可能な衣生活教育プログラム**（数回構成の授業・ワークショップ【要確認：実施形態】）を開発・実施する（参加者60名程度、介入群・統制群【要確認：デザイン】）。

- 研究成果を学会発表・学術誌投稿（英文誌を含む）により公表し、報告書を提出する。本研究のAI実験の知見は、次期研究課題（AIを本格的に活用した衣生活教育研究）の予備的根拠と位置づける。

**研究が計画どおりに進まない場合の対応**

- 海外協力大学の確保が困難な場合：応募者の既存ネットワーク（カーティン大学、ノルウェーの調査協力者、ARAHE・IFHEを通じた研究者網）を優先的に活用し、それでも不足する地域は国際調査会社パネルによるオンライン調査に切り替える。
- 企業関係者インタビューは実現可能性に不確実性があるため、本研究の必須要素とはせず、補完的位置づけとする（主軸は大学生調査）。
- 渡航が困難となった場合は、オンライン（Zoom等）でのインタビュー・協力依頼に代替する。

# ２ 本研究の着想に至った経緯など（1頁以内）

## (1) 着想に至った経緯と準備状況

応募者は約20年間、大学でファッション分野の人材育成に従事し、被服学・衣生活教育、およびファッション教育の国際比較研究を行ってきた。12年前にオーストラリア・カーティン大学を訪問してファッション教育の調査を行い、その成果を『オーストラリアのファッション教育―アクティブラーニングからエンゲージドラーニングへ』【要確認：書誌情報】として公表した。また10年前にはノルウェーで調査を実施し、北欧の生活文化・消費文化に関する知見と現地ネットワークを得た。

近年、学生の衣服消費がファストファッションに大きく依存し、大量購入・短期廃棄が常態化する一方、サステナビリティへの関心は高いという態度－行動ギャップを教育現場で日常的に観察してきた。この問題意識から、令和8（2026）年度に学内研究費を得て、日本・台湾・韓国の大学生を対象とするファストファッション消費行動のオンライン比較調査に着手した（本応募時点で完了予定【要確認：進捗に合わせ記載修正】）。その過程で、アジア圏内の差異に加え、ファッション文化の発信地（ミラノ・パリ）、サステナビリティ先進圏（北欧）、英語圏消費市場（オーストラリア）との比較なくしては、日本の学生の消費行動の特質と教育課題を国際的に位置づけられないとの着想に至った。

調査票・分析枠組みはアジア調査で確立済みであり、カーティン大学・ノルウェーの既存ネットワーク、ARAHE・IFHEでの発表を通じた研究者交流という調査基盤も有する。準備は整っている。

## (2) 関連する国内外の研究動向と本研究の位置づけ

海外では、サステナブルファッション消費研究が2010年代以降急速に発展し、態度－行動ギャップ、衣服廃棄行動、スローファッション等の研究が蓄積されている【要確認：主要文献】。しかしその多くは単一国調査か欧米圏内の比較にとどまる。国内では、衣生活教育・消費者教育の研究蓄積はあるものの、大学生の衣服消費行動を欧米と共通設計で比較した実証研究はほとんどない。また、生成AIを衣生活・消費者教育の学習支援に用いた介入研究は国内外を通じて緒に就いたばかりである。本研究は、①アジア・欧州・オセアニアを横断する共通設計の国際比較、②比較知見の教育介入への還流、③生成AI活用実験の三点を接続する点で、国内外の研究動向の空隙を埋めるものである。

# ４ 人権の保護及び法令等の遵守への対応（1頁以内）

本研究では、国内外の大学生を対象とするオンライン質問紙調査、および海外の大学教員・学生・企業関係者へのインタビュー調査を実施するため、以下の対策を講じる。

1. **倫理審査**：調査実施に先立ち、所属機関の研究倫理委員会【要確認：委員会名称。所属機関にない場合は関連学会・協力機関の倫理審査を利用】の承認を得る。海外協力大学での調査配信にあたっては、当該大学の倫理審査・調査実施手続きにも従う。
2. **インフォームドコンセント**：調査対象者に対し、研究目的、方法、参加の任意性、途中撤回の自由、データの利用範囲を対象者の言語で文書により説明し、同意を得たうえで実施する。
3. **個人情報の保護と海外データの取り扱い**：オンライン調査は無記名式とし、個人を特定できる情報は収集しない。EU圏（イタリア・フランス・北欧）の対象者データについては、**EU一般データ保護規則（GDPR）** の趣旨に沿い、協力大学の指針に従って取得・保管・利用する。インタビューデータは匿名化（仮名化）して分析し、パスワード保護された記録媒体に保管、研究終了後一定期間（5年）保管のうえ復元不可能な方法で破棄する。
4. **企業関係者インタビュー**：所属企業の許可と本人の同意を得たうえで実施し、企業秘密に関わる情報は収集・公表しない。
5. 個人情報保護法および所属機関の個人情報保護規程を遵守する。
