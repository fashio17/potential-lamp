# 旅費積算案（令和9年度・1年目）フランス（パリ）＋イタリア（ミラノ）

**目的**：1年目の補足現地調査（パリでの補足聞き取り＋ミラノでの補足聞き取り、パリ・ニューヨークと同一手続き）
**想定**：研究代表者1名／10日間（機中泊含む・現地9泊）／エコノミークラス／東京（成田）発着のオープンジョー（成田→パリ／ミラノ→成田）

| 費目 | 内訳・単価 | 金額（円） |
|---|---|---|
| 航空賃 | 成田⇄欧州 往復（燃油サーチャージ・空港使用料込、オープンジョー） | 300,000 |
| 現地間移動 | パリ⇄ミラノ（航空 or TGV/ユーロスター）片道相当 | 25,000 |
| 宿泊費 | 20,000円 × 9泊 | 180,000 |
| 日当 | 4,000円 × 10日 | 40,000 |
| 現地交通費 | 市内メトロ・鉄道・タクシー等（10日分） | 20,000 |
| 海外旅行保険 | 10日間・1名 | 15,000 |
| **合計** | | **580,000** |

**まるめ**：約58万円（≒60万円弱）

## 前提・注意
- 単価はすべて目安。**所属機関（東京家政大学）の旅費規程**に合わせて日当・宿泊上限を調整すること。
- 航空賃は時期・為替で変動。**科研費申請時は原則として実勢価格（見積・実績）に基づく積算**が望ましい（可能なら旅行代理店の見積を1点取得）。
- 人数を2名（代表＋分担）にする場合は、航空賃・宿泊・日当・保険を概ね2倍（現地間移動も人数分）。
- 通訳・調査協力謝金、逐語録の文字起こし委託費は「人件費・謝金」費目として別途計上（旅費には含めない）。
- 本様式S-14本文では渡航は「1年目のフランス・ミラノ」で記載済み。経費調書（旅費）と整合させること。
