# ファッション起業 7つのステップ（6ヶ月講座 受講生向け教材）

6ヶ月実践講座の「全体像の回」で使う教材一式です。受講生向けなので、講座案内・価格の話は入れていません。

## 設計の前提

**受講生の内訳：パーソナルスタイリスト・イメージコンサルタントが3、物販（ブランド・EC）が1。**
本文は**診断メニューを持つ方を主軸**に書き、物販の方向けは各パートに「▷ 物販の方は」として置き換えを1行添えています。

**7つのステップは器です。中身はファッション心理学とコーチングです。**
マーケティングだけを教える教材にならないよう、各ステップに「▶ 心理学の使いどころ」「▶ コーチングの使いどころ」を入れています。

## 2本の柱

| 柱 | 内容 |
| --- | --- |
| ファッション心理学 | ファッションの**観念（思い込み）**を洗い出し、書き換える。**DISCOVERY**（自己を見つめる・自分インタビュー・過去の体験）→ **AWAKENESS**（気づき・家族の観念）→ **Circulation**（書き換え・執着の手放し・フォーカス先を変える・願望ワーク） |
| コーチング | 本音を引き出す。**「似合う」と「なりたい」のズレ**を扱う。個別相談も同じ技術。自分を整えるセルフコーチングも含む |

## 7つのステップ

| # | ステップ | 内容 |
| --- | --- | --- |
| 1 | 価値の言語化 | 資格名を並べるのをやめる。専門性／提供できる変化／価値観 |
| 2 | 選ばれる理由を決める | 理想のお客様と「深いほうの詰まり」。診断はコモディティ、観念まで扱えることが理由になる |
| 3 | 商品設計 | 診断単発から抜ける3層。診断＝入口、本命＝観念のワークまで含む継続、継続＝同行・養成講座 |
| 4 | 発信設計 | 7つの心理ステップ（憧れ→信頼→共感→応援→気づき→自分ごと化→行動）を1週間で1周 |
| 5 | 販売導線 | Instagram → プロフィール → LINE → 教育 → 個別相談 → 本命商品 |
| 6 | セッション設計 | 聞く→気づいてもらう→**診断**→書き換える→実践。診断は3番目 |
| 7 | 仕組み化・自動化 | UTAGE / L Message / AI。1〜5が固まってから |

**設計の原則**：上から下へ情報が流れる。詰まったら必ず一つ上に戻る。STEP7の自動化は最後。

## この教材で統一している言葉

- 「売れる」は結果、「**選ばれる**」は原因
- 診断＝**入口**であって、商品そのものではない
- お客様の「**観念**」（ファッションに対する思い込み）
- 商品は「入口商品・本命商品・継続商品」
- うまくいかない理由を、受講生の**能力のせいにしない**（「まだ設計ができていないだけ」）
