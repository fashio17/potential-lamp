6ヶ月実践講座の「全体像の回」で使う教材一式です。受講生向けなので、講座案内・価格の話は入れていません。

## 7つのステップ

既存教材の「選ばれるために必要な5つの土台」と、6ヶ月講座の Phase1〜6 を再構成したものです。

| # | ステップ | 内容 |
| --- | --- | --- |
| 1 | 価値の言語化 | 専門性／提供できる変化／価値観 |
| 2 | 選ばれる理由を決める | 理想のお客様、その人の「詰まり」、あなたを選ぶ理由 |
| 3 | 商品設計 | 入口商品・本命商品・継続商品の3層 |
| 4 | 発信設計 | 興味／信頼／欲しい の3種に分ける。リール・教育動画の型 |
| 5 | 販売導線 | Instagram → LINE → 教育 → 個別相談／EC購入 |
| 6 | コーチングセールス | 聞く→整理する→提案する。セルフコーチング |
| 7 | 仕組み化・自動化 | UTAGE / L Message / AI活用 |

**設計の原則**：上から下へ情報が流れる。詰まったら必ず一つ上に戻る。STEP7の自動化は1〜5が固まってから。

## この教材で統一している言葉

ブレると受講生が混乱するため、以下で統一しています。

- 「売れる」は結果、「**選ばれる**」は原因
- **サービス型**（パーソナルスタイリスト等）／**物販型**（ブランド・EC）── どちらか一方に寄せず、必ず両方の例を出す
- 商品は「**入口商品・本命商品・継続商品**」
- 発信は「**興味を持たれる／信頼される／欲しいと思われる**」
- うまくいかない理由を、受講生の**能力のせいにしない**（「設計がまだできていないだけ」）
