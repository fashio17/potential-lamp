## 3. 必ず守るルール

### 画づくり

- **冒頭の1枚目に必ず人を写す。** 止まった風景・資料・文字だけはNG
- 毎回ちがう冒頭の画にする。過去に使ったカットは使い回さない

### テロップ

- **「。」は使わない**
- 位置は画面中央やや下。1080×1920 で **y=1180 前後**。顔とUIを避ける

### 使わない言葉

```
設計 / 逆算 / 導線 / ポジショニング / 順番 / 層 / 上・下
「習っていないだけ」
```

### 書き出し

- 1080×1920 / 30fps / H.264
- **無音のAACトラックを付ける**

### 運用

- 投稿時間：**日本時間 19〜22時**（本人はアメリカ在住・現地朝6〜9時）
- 評価は48時間ではなく **1週間**で見る（保存が多いと後から伸びる）

## 5. リンクタップ0の診断（2026-08-08）

### 症状

- リールからのリンクタップが3本連続でゼロ
- プロフィール到達は全部フォロー

### 診断

リールが失敗しているのではなく、**フォローで完結してしまっている**状態。

1. 「場所 + 観察 + 常識の否定 + 言い切り」の型は「この人の見方をもっと見たい」という気持ちを起こす。その気持ちのいちばん近い出口はフォローボタン。LINEに登録する理由はリールの中に一度も出てこない。売り込まないルールを守った結果として、そうなるのが自然
2. リールからLINEに届くまで、リール → プロフィールアイコン → プロフィール画面 → URL → 外部ブラウザ → LINE と**5回タップ**が要る。50代60代のメイン層でここを踏破する人はほとんどいない

### 方針

**リールでリンクタップを取ろうとしない。** リールはフォロー獲得の役割のまま置き、リンクは別の場所で取る。

### 受け皿4つ

1. **ストーリーズのリンクスタンプ（最優先）**
   リールが伸びている投稿後3〜7日、ストーリーズに旅の続きを出して最後の1枚にだけリンクスタンプ。タップ1回で届く。旅の続きが主役なので売り込みにならない
2. **プロフィール文のURL直前の1行**
   `未経験から始める7ステップ（無料）↓`
   案内であって売り込みではないので、教授という立場と矛盾しない
3. **固定コメント**
   自分のリールに自分で最初のコメントを書く。「ここはブルックリンの◯◯通りです」のような補足を主役にして、最後に1行だけ「7ステップはプロフィールから」
4. **2本目「先に決めてある編」の直後だけストーリーズを厚くする**
   唯一の売り込み型なので、この1本だけLINE登録に集中させる。他の3本はリンクタップの数字を見ない

### 見る数字

リールごとのリンクタップを追うのをやめ、**週あたりのLINE登録数**に切り替える。
リールが入り口、ストーリーズが受け皿の2段構えなので、リール単体のリンクタップは0のままで問題ない。

## 8. 素材の共有方法

Googleフォトを直接つなぐコネクタは存在せず、iPhone本体の中も直接は見られない。共有するには次のどちらか。

- **少量** — iPhoneのClaudeアプリで ＋ → 写真ライブラリ から直接添付
- **多いとき・繰り返し使うとき** — Googleドライブに `リール素材_YYYY-MM` フォルダを作り、iPhoneの写真アプリ → 共有 → Googleドライブ で入れる。以降は「あのフォルダを見て」で済む

読み取りの可否：

| | |
|---|---|
| 写真（JPEG/PNG） | 中身まで読める。素材選定・カットの並び・テロップ文言・キャプションまで作れる |
| 動画クリップ | **中身は読めない。** 要になる場面をスクリーンショットして一緒に入れる |

動画の編集・書き出し自体はCapCutやInstagram側での作業になる。こちらで作れるのは台本・テロップ・尺配分・キャプション。
