## 5. リンクタップ0の診断（2026-08-09）

### 症状

- リールからのリンクタップが3本連続でゼロ
- プロフィール到達は全部フォロー

### 診断

リールが失敗しているのではなく、**フォローで完結してしまっている**状態。

1. 「場所 + 観察 + 常識の否定 + 言い切り」の型は「この人の見方をもっと見たい」という気持ちを起こす。その気持ちのいちばん近い出口はフォローボタン。LINEに登録する理由はリールの中に一度も出てこない。売り込まないルールを守った結果として、そうなるのが自然
2. リールからLINEに届くまで、リール → プロフィールアイコン → プロフィール画面 → URL → 外部ブラウザ → LINE と**5回タップ**が要る。50代60代のメイン層でここを踏破する人はほとんどいない

### 方針

**リールでリンクタップを取ろうとしない。** リールはフォロー獲得の役割のまま置き、リンクは別の場所で取る。

### 受け皿4つ

1. **ストーリーズのリンクスタンプ（最優先）**
   リールが伸びている投稿後3〜7日、ストーリーズに旅の続きを出して最後の1枚にだけリンクスタンプ。タップ1回で届く。旅の続きが主役なので売り込みにならない
2. **プロフィール文のURL直前の1行**
   `未経験から始める7ステップ（無料）↓`
   案内であって売り込みではないので、教授という立場と矛盾しない
3. **固定コメント**
   自分のリールに自分で最初のコメントを書く。「ここはブルックリンの◯◯通りです」のような補足を主役にして、最後に1行だけ「7ステップはプロフィールから」
4. **2本目「先に決めてある編」の直後だけストーリーズを厚くする**
   唯一の売り込み型なので、この1本だけLINE登録に集中させる。他の3本はリンクタップの数字を見ない

### 見る数字

リールごとのリンクタップを追うのをやめ、**週あたりのLINE登録数**に切り替える。
リールが入り口、ストーリーズが受け皿の2段構えなので、リール単体のリンクタップは0のままで問題ない。

### 「受け取り方」ハイライトの中身（4枚）

ハイライト名：**🎁受け取り方**
フォロワー上位2アカウント（saki 9.8万・エクリュ 2.5万）だけが持っていた形。
**案内であって売り込みではない**ので、教授という立場と矛盾しない。

50代60代のメイン客には、「プロフィールのリンクを押す」という操作そのものの説明が要る前提で作る。

### 9-1. 正式版（LP用・7行）

**ステップ1　自分の「好き」を棚卸しする**
これまでの経験、好きなこと、得意なことを並べて、あなたの武器をはっきりさせます。

**ステップ2　誰に届けるかを決める**
どんな方の、どんなお悩みを解決するのかを決めます。ここが決まると、発信が迷わなくなります。

**ステップ3　自分の立ち位置を決める**
似た人がたくさんいる中で、あなただけの場所をつくります。

**ステップ4　「似合う」の先を、言葉にする**
ファッション心理学を使って、お客様の気持ちに寄り添いながら、選ばれる提案へつなげます。ただ似合うを提案するだけでは、仕事になりません。

発信して終わりではなく、興味を持たれ、信頼され、ご登録・お申し込みへとつながる流れをつくります。

**ステップ6　AIに下書きをさせる**
投稿ネタの整理、言いたいことの言語化、講座案内文の下書きなど。感性はご自分のまま、手間だけを減らします。

**ステップ7　一度つくった流れを、何度も使う**
集客から販売までを毎回ゼロから頑張るのではなく、一度整えた流れを繰り返し使えるようにします。

### 9-4. 第4章を最長（85秒）にした理由

競合4人の誰も持っていない部分。話す骨は3つ。

1. **なぜ「似合う」だけでは仕事にならないか** — 診断結果は情報であり、情報は無料で手に入る。お金が動くのは、その人の「こうなりたい」に届いたとき
2. **服は自己概念の表れ** — 「似合う」は他人からの見え方の話、「なりたい」は自分の内側の話。両方を扱えて初めて提案になる
3. **言い切る** — 伸びたリールと同じ型。ここで一度はっきり言い切る

他の人の無料特典は3番目以降（集客のやり方）から始まる。本人は1章から4章まで服の心理の話ができる。

### 9-5. 各章の「よくあるつまずき」

売り込みにならず、聞き手が自分ごとにできる形。各章に1つずつ入れる。

| 章 | つまずき |
|---|---|
| 1 | 「特別な経験がない」と思ってしまう（服が好きな気持ちが続いていること自体が武器） |
| 2 | 全員に届けようとして、誰にも届かない |
| 3 | 差をつけようとして奇抜になる |
| 4 | 診断結果を伝えて終わってしまう |
| 5 | 投稿数だけ増えて、信頼が積み上がらない |
| 6 | AIに全部書かせて、自分の言葉でなくなる |
| 7 | 毎回新しいことをやろうとして続かない |

### 9-6. 締めの方針

2025年4月の旧版（Notion「教育動画シナリオ」）は「今すぐLINEに登録して、特典＋相談を申し込んでください」で終わっていた。**今回は変える。**

```

```

視聴者はすでにLINE登録済みなので、ここで売り込む必要がない。講座の案内を入れるとしても1文。

## 12. 素材の共有方法

Googleフォトを直接つなぐコネクタは存在せず、iPhone本体の中も直接は見られない。共有するには次のどちらか。

- **少量** — iPhoneのClaudeアプリで ＋ → 写真ライブラリ から直接添付
- **多いとき・繰り返し使うとき** — Googleドライブに `リール素材_YYYY-MM` フォルダを作り、iPhoneの写真アプリ → 共有 → Googleドライブ で入れる。以降は「あのフォルダを見て」で済む

読み取りの可否：

| | |
|---|---|
| 写真（JPEG/PNG） | 中身まで読める。素材選定・カットの並び・テロップ文言・キャプションまで作れる |
| 動画クリップ | **中身は読めない。** 要になる場面をスクリーンショットして一緒に入れる |

動画の編集・書き出し自体はCapCutやInstagram側での作業になる。こちらで作れるのは台本・テロップ・尺配分・キャプション。
