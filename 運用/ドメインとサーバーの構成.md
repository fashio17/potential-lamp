# ドメインとサーバーの構成（2026年9月5日・ご本人に確認）

| | |
|---|---|
| ドメイン | **お名前.com** で取得 |
| サーバー | **エックスサーバー** |
| そこで動いているもの | **info@ などのメールアドレス**／ホームページ（現在は更新していない） |
| 申込ページ・LP・会員サイト | **UTAGE**（utage-system.com。AWS東京。Cloudflareは入っていない） |

## Cloudflareの件（保留）

2026/9/5に「ホームページを速く・安全にしたい」というご相談がありましたが、
**またの機会に**ということで保留になりました。

**再開するときに、必ず先に読むこと。**

- Cloudflareを入れる作業の本体は、**お名前.comのネームサーバーをCloudflareのものに切り替える**こと。
- **このドメインでは info@ のメールを使っています。**
  ネームサーバーを切り替えるとき、**エックスサーバーのMXレコードを写し損ねると、メールが届かなくなります。**
  Cloudflareは既存レコードを自動で読み込みますが、**MXとTXT（SPF）は毎回、目視で確認すること。**
- 反映に**最大24時間**かかるため、戻すのにも時間がかかる。
  **配信やイベントの直前にはやらない。**
- そもそも、ホームページを更新していないのなら、**やる価値があるかどうかから確認する。**
  UTAGEのページはCloudflareの対象外なので、速くなるのは放置しているサイトだけです。

## 作業前に必ず控えておくもの

エックスサーバーの管理画面 → DNSレコード設定 で、以下を全部スクリーンショットに残す。

- **MXレコード**（メールの宛先。これが最重要）
- TXTレコード（SPF・DKIM。メールが迷惑メール扱いされないための設定）
- A / CNAME レコード
