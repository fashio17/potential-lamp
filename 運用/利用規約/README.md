## 1. 講座の芯（ここを外さない）

> **この講座は、ご自分で自律して起業するためのものです。**（ご本人・2026/9/21）

規約 **第1条3項**：

> 本プログラムの目的は、**受講者に代わって事業を運営することではなく**、
> 受講者自身が発信、商品づくり、事業運営等を行うために必要な
> 知識、考え方および実践方法を習得することにあります。

規約 **第3条（受講者の主体性）**：

> 発信、商品・サービスの企画、事業活動および意思決定の**主体は、受講者本人**です。
> …講師からの指示どおりに行動することを目的とするものではなく、
> **受講者自身が考え、判断し、継続的に実践できる能力を身につけること**を目的とします。

**この2つが、すべての文面の下敷きです。**

## 2. 含まれない業務（規約 第4条3項）

発信で「やります」と書いてはいけないものです。

| | 含まれないこと |
|---|---|
| （1） | 受講者に代わって行う市場・業界・競合の**包括的な調査** |
| （2） | 事業計画・商品企画・販売戦略の**全面的な策定または作成代行** |
| （3） | SNS投稿、動画、画像、LP、ECサイト、申込ページの**継続的な制作代行** |
| （4） | 受講者に代わって行う販売、営業、顧客対応、SNS運用 |
| （5） | すべての行動について**個別具体的な指示を継続して行うこと** |
| （6） | 税務、法務、医療その他**専門資格を必要とする助言** |
| （7） | その他、教育および助言の範囲を超える業務 |

**「質問し放題」と書いてあっても、上記は含まれません**（規約 第6条3項に明記）。

## 3. 成果について（規約 第5条4項・第24条）

**保証しないと決まっているもの**：フォロワー数の増加／売上／利益／契約数／
集客数／就業／独立／事業の成功。

受講生の声に数字を出すときは、**かならず添える**：

> 成果には個人差があります。特定の成果を保証するものではありません。

## 4. 言い換えの決めごと

**左は使わない。右に置き換える。**

| 使わない | 使う |
|---|---|
| その場で**一緒に作ります** | **ご自分の手で作っていただきます。**操作でつまずいたところは、その場でお手伝いします |
| 画面を見ながら**ご一緒します** | 画面を見ながら、**操作のご案内をします** |
| 続けられる形にするところまでを**一緒にやります** | 手順と考え方をお伝えします。**手を動かすのはご本人です** |
| **伴走**します／伴走型 | **お一人ずつに目が届く形**にしています |
| **ファーストキャッシュをとる** | はじめての販売に向けて、**ご自分で動けるようにする** |
| ビジネスを立ち上げるところまでを**ご一緒します** | **ご自分でビジネスを立ち上げられるようになるまで**をお手伝いします |
| **やってあげます／代わりに** | （使わない） |
| **あなたに合わせて全部作ります** | （使わない） |

**「一緒に」という言葉じたいは禁止ではありません。**
ただし **主語がご本人になっているか**を、必ず確かめてください。
「一緒に作る」は危ない。「ご自分で作る。つまずいたらお手伝いする」は安全です。

## 4-2. 期間の決めごと（2026/9/21にご本人が決定）

| | いつまで |
|---|---|
| **講義・対面ワークショップ・質問対応** | **受講期間中のみ**（「一」「二」は3ヶ月、「三」は6ヶ月） |
| **動画講座の会員サイト・講座アーカイブ** | **開講日から1年間** |

**「1年間」を質問対応にまで広げないこと。**
広げると「三」は講座が終わったあと半年、質問を受け続ける形になります。
書くときは必ず「質問し放題（受講期間中）」「会員サイトとアーカイブは開講から1年間」
と、2つに分けてください。
