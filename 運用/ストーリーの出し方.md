# ストーリーの出し方（勉強会 9/2〜9/12）

「何を書くか」より先に、**操作でつまずかないこと**を目的にした手順書です。
分からなくなったらここに戻ってきてください。

---

## 1. 基本の操作

### いちばん使うもの：リンクスタンプ

ストーリーからお申し込みページに飛ばす方法です。これができれば足ります。

1. インスタを開いて、左上の自分のアイコン（＋のついたもの）をタップ
2. 写真を撮る、または左下からカメラロールの写真を選ぶ
3. 上のほうにある **スタンプのアイコン**（四角い顔のマーク）をタップ
4. 一覧から **「リンク」** を選ぶ
5. URLを貼り付ける
6. その下の **「スタンプのテキストをカスタマイズ」** で、表示される文字を変える
   → 「詳しくはこちら」ではなく **「無料で申し込む」** のほうが押されます
7. 貼られたリンクを指で動かして、文字と重ならない位置に置く
8. 右下の「ストーリーズ」で投稿

**貼るURL（勉強会のお申し込みページ）**

```
https://utage-system.com/event/eD8W2PGPdZOT/register
```

このURLは長押しでコピーできます。スマホのメモ帳に一度貼っておくと毎回ラクです。

### リールをストーリーに流す

新しく作らなくていい方法です。**投稿日はまずこれをやってください。**

1. 投稿したリールを開く
2. 下にある **紙飛行機のアイコン**（送信マーク）をタップ
3. **「ストーリーズに追加」** を選ぶ
4. 出てきた小さなリールの画像を、指で少し大きく／好きな位置に動かす
5. 上に一言だけ文字を足す（例：「新しい投稿です」ではなく「3カ国まわって、結論が出ました」）
6. 投稿

リールを見ていない方の目にも触れます。手間は30秒です。

### ハイライト（プロフィールに残す）

ストーリーは24時間で消えますが、ハイライトにすると残ります。
**勉強会が終わるまで、申し込みのストーリーは必ずハイライトに入れてください。**

1. 投稿済みのストーリーを自分で開く
2. 右下の **「ハイライト」** をタップ
3. 「新規」→ 名前を **「勉強会」** にする

一度作れば、次からは同じハイライトに追加していくだけです。

## 2. 続けるためのルール

- **1日1〜2枚で十分です。** 毎日たくさん出す必要はありません。
- **1枚に1つのことだけ。** 文字は3行まで。長いと読まれません。
- **リンクは、その日の最後の1枚に貼る。** 全部に貼ると広告に見えます。
- 顔が写っていなくてかまいません。手元、服、風景、文字だけ、どれでも成立します。
- **他の方の顔は絶対に入れない。** リールと同じ決めごとです。

## 4. これだけは

- **リンクスタンプを貼らないと、ストーリーは申し込みにつながりません。**
  文字だけのストーリーは、見られても終わりです。
- **プロフィールのリンクも同じURLにしておいてください。**
  ストーリーを見逃した方の受け皿になります。
- どうしても操作が分からないときは、**リールをストーリーにシェアするだけ**でも出してください。
  出さない日をつくらないほうが効きます。
