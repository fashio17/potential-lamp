## 1枚目について

**R3（9/14投稿）と対になっています。** リールの中身をそのまま文字にしてあるので、
リールを見ていない方にも届きます。

**R3を投稿したら、まずリールそのものをストーリーにシェアしてください**
（紙飛行機 →「ストーリーズに追加」）。そのうえで、この1枚目を続けて出すと効きます。

## 2枚目について

**中身を先に全部書く形にしてあります。** 金額を伏せない、向いていない方も言う、という
これまでの出し方と同じです。LINE⑧で予告していた内容をストーリーに移しました
（LINEの一斉配信は9/13に止めたため）。
