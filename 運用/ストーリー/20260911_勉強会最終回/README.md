## 3枚目について（読んでから出してください）

**申込は現在1名です**（9/11にUTAGEで確認。9/12 21:00-22:30の回）。

3枚目は、その状況を**隠さずに、来る理由に変える**ための1枚です。
「人が少ない会」ではなく「ひとりずつ聞いてもらえる会」として書いてあります。

**あえて「1名です」という数字は書きませんでした。** 「まだわずかです」にしてあります。
数字を出すと、来る理由になる方と、かえって引く方に分かれます。
はっきり出したいときは、build.py の3枚目を
`最終回のお申し込みは、いまのところ1名です。` に変えて作り直してください。
